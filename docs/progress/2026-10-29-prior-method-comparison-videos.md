# 光纤先验方法及同步视频对比

本次根据用户要求，为video_1和video_2分别制作全片同步对比。已失败方案也保留展示，不更改原有验收结论、权重、阈值或默认模型。只比较当前可见分割；不将历史推测形状填为真实光纤，也没有启动结石对象记忆。

## 尝试过的方法

以下按视频中的编号列出8个先验变体，归属4类方法。所有几何均为未作设备标定的二维图像假设，不能由此保证真实尖端、尺寸或激光落点准确。

| 面板 | 方法及先验 | 如何改变分割 | 29帧光纤Dice |
|---|---|---|---:|
| 参照1 | 原始三网类别组合：old190结石＋A0双网光纤 | 无几何先验，光纤优先融合 | 0.966802 |
| 参照2 | 旧190单网 | 原始三分类输出 | 0.903830 |
| 先验1 | **边缘几何拟合**：邻近视野入口、细长主干、两条直边、圆钝端帽 | 从神经分割候选出发，逐帧鲁棒拟合两侧边缘与半椭圆端帽；通过时以拟合几何和当前概率/原掩膜支持相交，失败回退原掩膜 | 0.955336 |
| 先验2 | 边缘几何＋**因果姿态跟踪** | 在先验1上用alpha-beta滤波跟踪位置、角度、长度和宽度；跳变时重置，只有历史预测时不修改可见掩膜 | 0.955569 |
| 先验3 | **几何候选筛选（三网）**：入口连接及同一管状形状检查 | 几何通过时保留选中组件的原始边界，只删除其他组件；失败保留全部原始光纤，不用理想轮廓裁主干 | 0.966583 |
| 先验4 | 几何候选筛选（旧190单网） | 同一筛选规则，光纤候选改为old190自身输出，用于测试单网可行性 | 0.902696 |
| 先验5 | **共享固定模板＋颜色观测**：固定锥度及圆形端帽，只变入口/角度/长度 | 不从最大分割组件起步，直接在全视野搜索；用TRAIN颜色后验与RGB边缘评分，接受后模板与当前颜色支持相交 | 0 |
| 先验6 | 固定模板＋**神经软评分** | 先验5评分额外加入A0概率奖励；颜色仍决定接受检查和当前可见支持，因此未消除颜色失配 | 0 |
| 先验7 | 固定模板＋**因果姿态约束** | 在软评分定位中加入既往姿态预测与运动惩罚；当前可见支持仍是颜色，历史状态不强制输出光纤 | 0 |
| 先验8 | 固定模板＋**神经概率观测** | 用冻结A0概率替换颜色前景场，同时作用于评分、接受和可见支持；不叠加先验6额外软奖励，形状/搜索/阈值均不变 | 0.883211 |

“四类”分别为：边缘拟合及其因果跟踪、候选筛选、固定模板的颜色/软评分/因果版本、固定模板的概率观测版本。固定模板共享参数来自上一轮TRAIN521中的31张合格样本；本次没有重估形状。先验1/2的每帧宽度和端帽拟合，与先验5–8的共享固定形状不相同。

上述方案均未替换默认模型。先验3通过29帧初筛，但真实像素略损失、成本增加，没有采用；其余先验变体未过原光纤门槛。颜色场的失败不代表所有形状先验无效；概率场的退化也需要区分自动姿态定位与形状失配。

## 阅读成片

每段视频为4列×3行：原画面、参照1、参照2、先验1、先验2、先验3、先验4、先验5、先验6、先验7、先验8、说明栏。每个影像面板保持400×400，整片1600×1436；红色为结石，青色为光纤，光纤另有细轮廓以便区分原本呈蓝色的RGB外观。所有面板按同一个原始帧号同步，保留原视频帧率与全片范围。

字幕Dice仅来自固定29帧像素参考，不能解释为2694帧全片精度；片中没有增加任何参考掩膜或人工提示。实际录制的手术图像、单网基线和各种失败输出均按原样保留，因此一些面板可能漏检、裁切、误检或长时间没有光纤。

先验4和先验8此前仅做了29帧/132图像的静态对照。本次按用户明确要求补充完整顺序推理，**仅用于展示**：不属于静态门槛通过后才允许的验收回放，不更改两次原实验的静态失败、未开展条件性因果回放等历史记录。先验8本次仍为无状态当前帧推理，没有新增其因果变体；先验2/7复用已有每病例重置的历史因果结果。

其余8组参照/先验输出直接读取已完成实验的原图PNG，避免重新运行改变历史结果。新补充的两组保留全部5388张原图掩膜、逐帧接受/拒绝记录，原视频、权重和代码身份另存。本次无训练、阈值扫描、共享标定或默认模型修改；视频仍仅作开发验证。
