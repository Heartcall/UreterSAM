# 光纤时序几何状态T0对照

2026-10-30。**已完成四臂、8个独立进程、两片各722/1972帧，共10776帧。异常门控机制实现并通过核验，但可视化出现跟随延迟，完整几何管线也未满足源帧预算，不采用为默认。分割掩膜逐像素不变，本轮没有分割准确率改善。**

按执行前冻结方案，raw2、逐帧当前几何观测、旧alpha-beta状态、新门控状态共用相同model1两网底座。三几何臂的当前RGB/FOV/边缘/端帽拟合逐帧相同；旧拟合器/跟踪器、alpha/beta和原跳变门槛未修改，新门控只改变异常怎样进入状态。入口、轴向、长度、宽度与端帽联合表示，末端和两侧方向由同一状态推导，不独立平滑。

新状态器将孤立越界观测暂存，连续3次彼此一致后在当前时刻重定位，不回改前两帧；最多3帧仅预测，第4帧清空，待确认不会借活动状态过期绕过确认。每视频/每静态图独立状态，预热后清空；源/分辨率/时间异常清空。预测只为独立元数据，不裁剪或填补可见光纤，不强连断片。

## 质量、验证与下一步

202张静态原图重新推理一次，各臂共享相同掩膜；70帧两专家概率与全部分割指标精确复现model1。视频/图像结石Dice为0.740216/0.906751，光纤为0.945537/0.765758，TP/FP/FN、边界及各原29/新41、病例、来源/曝光分组不变。10776帧均与已有model1原图掩膜一致，TP删除或恢复、FP增减全部0。先前model1相对三网严格不退化失败仍有效，未默认采用。

11项新增状态测试、3项旧几何回归及63项独立核验通过，包括全部原掩膜/来源身份、相同当前观测、旧状态独立重放、新状态全片与前缀因果重放、计时和10段视频导出。首次审计对归一化角度用了严格浮点相等而误报；已改为1e-12数值容差，初次日志保留，没有改实验状态器、门控阈值、源码或结果。

T0按固定四臂收尾，不再调门槛、确认数或TTL。下一步先制定T1低成本当前图像观测/历史辅助候选搜索的独立协议：历史只限定搜索位置，当前网络/双侧边缘/对比度提供证据，强当前证据应能覆盖历史，证据不足才更多依赖连续性；区分镜头运动与光纤变化的需要单列。先限定观测与拟合预算、全图保底、真实快速移动/无种子/遮挡回退，再设计有无历史对照。不能直接叠加旧重网裁剪、把预测轮廓填成可见光纤，或自动进入像素修正、训练、默认替换、结石S3。

视频及派生物不训练，stone_new全部训练排除，原521/132/144/29与活动70标签不变，本轮TRAIN/144保留test像素读取0。70帧是重复开发参考，42/120随机标注未完成，不外推全片精度；12帧尖端专项仍待补，Godot参数不作真实标定。
