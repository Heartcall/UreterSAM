# 自动局部精修 ROI 覆盖与成本诊断

2026-10-28。已完成 S2 下一步的六组固定配置诊断。**当前联合结石/光纤 ROI 方案均未满足冻结的覆盖与成本条件，不启动这套局部训练。** 光纤覆盖显示出局部精修的空间，但现有 U-Net 串行裁剪计算开销较大，不能据此宣称实时精修已实现。

## 范围与冻结协议

仅读取 video_1/video_2 的 29 帧开发验证图像和已审核像素标签，以及冻结的 kidney-only U-Net256 末轮权重。190 张训练图像和 800 张备用图像本轮均未读取；未更新任何模型参数，未训练、蒸馏或生成用于训练的伪标签。stone_new 继续全部排除。训练标签待审、病例来源待核实的状态保持不变。

候选区域仅从模型的原图概率生成：PIL RGB→256 输入→softmax→FP32 双线性概率映射回原图→argmax。精度诊断使用与上一轮相同的 batch 2 路径，29 张粗分割掩膜与冻结原图结果逐像素一致。

预先固定两种种子：最终类别（hard）和各前景概率≥0.2（soft）。逐类别取八连通组件，移除小于4个原图像素的组件，外扩16像素；使用192×192原图窗口，长组件按最大160像素步距覆盖，窗口整体平移以留在图像内。按两类各自总种子数归一化，贪心优先覆盖新增种子；并列按坐标确定顺序，避免大类别独占预算。每种种子比较最多2个、4个和不限数量窗口，重复或无新增种子窗口不保留。无种子则无ROI，不从真值补区域。

启动前冻结可行性条件：两类各自汇总像素覆盖率≥99%；每张有该类真值的帧覆盖率≥95%；窗口数p95≤2；包含一次粗分割的平均模型输入像素数小于全图256的4倍。每个裁剪拟输入256，故输入像素比为1+平均窗口数。这是工程可行性条件，不是分割验收或临床指标。配置、58项验证输入、源码、权重和参考结果身份均记录在预检中。

预算2时，video_1结石全部覆盖；video_2仅覆盖约81–82%，有6张结石帧不足95%。video_2零基索引1971的多个分散结石只能覆盖48.35%；增加窗口可改善该帧，但小结石漏检仍限制方案。

video_2零基索引1822的625个结石像素被粗分割完全漏掉；邻近其他预测区域让548个像素偶然进入ROI（87.68%），另外77个仍在区域外。不限窗口也未补齐。这不代表模型重新检出了该结石。原图总可见结石面积≤1024像素的3帧汇总覆盖96.82%，不能以大目标平均数替代小目标表现，也不能当作实例或物理尺寸结果。

hard最多2窗口的并集只占整帧面积32.19%，但面积较小不等于计算同比减少。此时可作用到21,734/25,251个结石漏检像素，及全部11,584个光纤漏检像素；覆盖20,957/23,968个光纤误检像素（87.44%），仍有3,011个区域外光纤误检像素无法由该精修路径处理。

## 统一流程的实际计算开销

每种配置在独立进程、batch 1、12帧预热和87次计时下运行。使用同一RGB/PIL预处理、原图概率及CPU类别输出流程；局部配置增加CPU区域生成和逐窗口256输入的模型调用。仍用冻结的原U-Net作为同形状计算代理，**并非已训练精修模型**，未将裁剪预测当作精度结果。计时不含解码、显示、输出融合、几何和记忆。

| 配置 | 中位耗时（ms） | p95（ms） |
|---|---:|---:|
| 同流程全图256参照 | 10.69 | 16.12 |
| 同流程全图512参照 | 17.47 | 22.64 |
| hard，最多2 | 31.84 | 43.64 |
| hard，最多4 | 33.37 | 55.55 |
| hard，不限 | 29.26 | 59.53 |
| soft，最多2 | 32.25 | 44.20 |
| soft，最多4 | 28.02 | 45.80 |
| soft，不限 | 31.53 | 55.76 |

模型输入像素预算通过也不能推导为延迟通过；多次模型调用、CPU候选区生成和传输的开销明显。单次本机测量存在波动，不按六组之间的小延迟差排序，也不据此宣称轻量精修必然慢于全图512。当前代理方案的28–33ms中位耗时已不支持其相对本轮同流程全图参照的速度优势。此前OpenCV/GPU输出测速口径不同，不能跨表混比。

第一次测速与工程测试有时间重叠，已保留作追溯，不采用其数字作主成本结论。上表来自测试全部结束后的独立补测及相同流程全图参照。

## 上界的含义、决定与下一步

另计算“自动ROI内所有有效像素均被完美纠正、区域外保留粗分割”的上界，未用真值选择ROI。hard最多2时，结石/光纤Dice上界0.9775/0.9916；hard最多4时为0.9983/1.0000。这说明区域内有可修正空间，**不是精修性能**。真实模型还会新增错误，不能用此上界宣告S2通过。29帧均有光纤真值，尚不能评价真正无光纤帧的行为。

本轮结论：

- 当前全目标联合ROI没有同时满足覆盖和预算，不扩大窗口、不修改门槛，不启动此配置的局部训练。
- 光纤在所有29帧均被自动区域覆盖，值得将后续假设收窄为**保留全图结石输出的光纤专用轻量精修**。新假设不能沿用“联合ROI已通过”的说法。
- 下一步先冻结光纤专用候选区及融合规则，核验保护结石输出后的光纤可修正上界、区域外误检和轻量分支成本；条件成立再冻结训练对照。仍只使用kidney训练图像生成训练裁剪，两个验证视频及其裁剪继续禁止训练。SSL保持暂缓，S3尚未进入。
