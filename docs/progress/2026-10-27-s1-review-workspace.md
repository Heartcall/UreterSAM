# S1 复核工作台实施记录

日期：2026-10-27。承接 [S2 工程准备](2026-10-27-s2-infrastructure.md)，优先降低 S1 剩余标注工作成本。本轮新增本地操作工具，未将来源待审或模型预标注提升为已审核证据，正式 A1 重训与 S3 尚未启动。

## 已交付

- 本地浏览器复核工作台，接入已对齐的 29 帧关键帧、6 段上下文视频和 2847 张训练草稿。
- 类别画笔、多边形、撤销、透明度、实例颜色与原图对照；使用原图分辨率保存类别标签和 16 位实例标签。
- 手动标记跨帧实例、多片区、部分/完全遮挡、失跟、离开视野、分裂待确认和父子身份。
- 候选负样本、光斑无光纤和未知类别筛选；来源线索与核实状态分开。
- 待审保存、显式审核、排除、版本保留、会话恢复、重复页面过期保存拒绝及来源/修订哈希检查。
- 自动导出兼容现有视频评价与训练清单升级工具的 JSON/CSV；像素审核不等于实例审核，标签修订不等于来源已核实。

核心文件：[存储与验证](../../tools/review_store.py)、[本地服务](../../tools/review_server.py)、[界面](../../tools/review_ui/index.html)。

## 验证

新增合成样本测试覆盖标签修订、保留原图、版本恢复、过期保存、数据审核条件、两片区同身份、完全遮挡、实例覆盖光纤拒绝、父子循环拒绝、未标身份拒绝、损坏版本拒绝、保存中断不改变当前版本、HTTP 服务及评价导出兼容。

浏览器中实测画笔与撤销、多边形、保存待审、审核、切换后重载，以及未核实来源时拒绝批准训练样本。测试保存操作只发生在独立合成样本会话，真实数据保持待审。真实数据浏览验证了候选负样本筛选。

完整自动测试共 41 项通过；其中本轮新增 10 项，包括不依赖浏览器视频编解码器的逐帧 JPEG 上下文回放。HTTP 测试使用回环网络，沙箱内连接被限制后，在允许回环访问的测试进程中完成，无外网请求。

最终核对 2876 个样本的原图和预标注哈希，真实会话没有保存审核决定；候选筛选数量与审计结果一致。32 个项目 Python 文件通过语法检查，原模型权重 SHA256 不变。浏览器确认上下文回放解码为 800×400，收起后仍显示未审核预标注。[检查记录](../../runs/engineering/review_workspace_checks_20261027.json)。

本工具只监听 `127.0.0.1`，没有新增外部服务或依赖。当前服务地址为 <http://127.0.0.1:8767>；操作说明与导出入口见 [工作台说明](../evaluation/review_workspace.md)。
