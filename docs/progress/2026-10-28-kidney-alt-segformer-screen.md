# A1-ALT：SegFormer-B0 同源监督短程对照

日期：2026-10-28。已完成 SegFormer-B0 与原 ResNet34 U-Net 的两组固定15轮训练。**本轮 SegFormer-B0 参数更少，但结石、光纤及边界指标更差，实测推理未提速；不采用为新主线。S2 仍未通过，暂不进入时序记忆集成。**

## 实现与可比范围

本机已有 segmentation-models-pytorch 0.4.0，本轮使用其 `Segformer(encoder_name="mit_b0", decoder_segmentation_channels=256)`，三分类、单网。其实现对应多尺度 MiT 编码与轻量解码的 SegFormer 设计，参考 [SMP 0.4 文档](https://smp.readthedocs.io/en/v0.4.0/models.html)与 [NVlabs 项目](https://github.com/NVlabs/SegFormer)。这是**完整网络对照**，不是只替换 U-Net 编码器，也不是复现 NVlabs 在自然图像上的训练配方。

MiT-B0 ImageNet 编码器权重来自 SMP 注册的[官方发布资产](https://github.com/qubvel/segmentation_models.pytorch/releases/download/v0.0.2/mit_b0.pth)，下载后固定 SHA256 为 `df468f7f13c4186f25bd3e2caf09e4f927b5b5ac0abccac84011dae747d4c49c`。权重以 `weights_only=True` 加载，178 项张量均为有限值，编码器严格加载成功；完整外科分割头随机初始化。没有使用混合来源外科权重或伪标签。详见[权重来源记录](../../runs/pretrained/mit_b0.provenance.json)。

增加了显式架构标识及推理加载支持；缺省仍为原 U-Net，旧 A0 可直接推理。新训练保存完整优化器/RNG断点。单网监督分支支持本模型，本轮不将其接入旧互学习/特征输出训练。

## 启动前固定的实验

- 两组均从 ImageNet 编码器与随机解码器开始，以 seed42训练15轮，各1425次有效参数更新、2850次训练图像使用。预训练编码器的训练经历不同，不能声称只控制了编码结构这一个变量。
- 相同 kidney-only 190张监督图像、256输入、batch2、均匀采样、几何增强、AdamW与余弦调度；学习率1e-4、共享CE/Dice类别权重[1,2,4]及Dice系数不变。
- stone_new继续禁止；800张备用图像本训练不读取；video_1/video_2的29帧仅开发验证。来源标签和病例对应关系保持待审。
- 主比较固定末轮，不因结果延长训练或重选最有利轮次。预先冻结2像素边界容差、整帧可见结石面积≤128模型像素的小目标分组；另计参数量、训练墙钟/显存、batch1推理成本。
- 比较相同更新次数，不是相同FLOPs或硬件耗时；没有为 SegFormer 单独调优学习率、损失或分辨率。因此本结果不能代表其性能上限或所有 Transformer 的优劣。

## 固定末轮精度

相同 PIL/256 模型网格、29帧全局累计混淆矩阵。负帧误检面积仅指9张无结石帧上误检结石像素比例，不代表整段视频误检持续时间。

| 指标 | A0 | U-Net单网 | SegFormer-B0单网 |
|---|---:|---:|---:|
| 结石 Dice | 0.4768 | 0.8110 | 0.7696 |
| 结石 Recall | 0.7439 | 0.7234 | 0.6489 |
| 光纤 Dice | 0.9699 | 0.9027 | 0.6404 |
| 光纤 Precision | 0.9924 | 0.8732 | 0.9761 |
| 光纤 Recall | 0.9485 | 0.9342 | 0.4765 |
| 光纤 FP / FN像素 | 533 / 3766 | 9913 / 4813 | 854 / 38267 |
| 负帧结石误检面积 | 7.7861% | 0.0331% | 0% |
| 有结石误检负帧数 | 6/9 | 1/9 | 0/9 |

SegFormer-B0 的较少误检伴随显著漏检，尤其是光纤，不将其0负帧误检解释为总体改善。选中第14轮的结石/光纤 Dice为0.7841/0.6748；历轮最高光纤Dice为0.8598，同样低于0.9599门槛。所有轮次均未同时通过共同门槛，未通过改选轮次宣布成功。

## 边界、小目标与失败帧

边界采用2像素欧氏容差、全帧累计边界 Precision/Recall 后求F分数；255未知区域邻域及图像边缘容差带不计入。该容差只属于256网格诊断，不是毫米或临床边界容许误差。

| 边界F分数 | A0 | U-Net | SegFormer-B0 |
|---|---:|---:|---:|
| 结石 | 0.5602 | 0.6067 | 0.5352 |
| 光纤 | 0.9227 | 0.7371 | 0.3932 |

29帧中没有整帧可见结石面积≤128模型像素的正帧，该分组数量为0、召回保存为null，**小目标性能未验证**。没有事后调大阈值获取一个分数，也没有把连通域当成已标注实例。

核对原图、审核掩膜及两模型预测，可见 SegFormer-B0 在部分帧只保留光纤的一段，漏掉杆体或中段；U-Net仍有近景腔壁被误认作光纤的失败。更低的中间特征分辨率可能是待检验因素，当前没有分辨率消融证据，不能直接确定因果。

## 本机成本及补充隔离测量

参数量 U-Net为24.60M，SegFormer-B0为3.71M，减少约84.9%。包含初始化、逐轮验证和断点保存的训练墙钟为96.25秒/147.06秒；训练CUDA峰值分配为474.8/259.6 MiB。相同更新预算下，小参数量没有带来本轮硬件上的训练加速。

原始训练后同进程测量：U-Net/SegFormer推理p50为10.09/21.61 ms，峰值分配193.8/125.7 MiB。观察到同进程分配值相对此前独立推理存在共同偏移，保留原始结果，并补充**逐模型新进程**测量，避免将此前模型的运行时保留分配计入另一模型。

| 新进程补充测量 | U-Net | SegFormer-B0 | A0双网 |
|---|---:|---:|---:|
| p50 / p95 | 6.26 / 11.11 ms | 22.11 / 23.07 ms | 10.18 / 19.66 ms |
| CUDA峰值分配 | 128.8 MiB | 93.7 MiB | 223.9 MiB |
| 释放模型后的CUDA保留分配 | 0 | 33.0 MiB | 0 |

两种口径都没有观察到 SegFormer-B0 提速。保留分配说明GPU运行时也影响显存读数，不能只用参数量推算。每个模型同为预热12帧、测量87帧、batch1、缓存原始BGR输入到概率/掩膜，采用现有OpenCV预处理；不含视频解码、显示、几何与记忆。计时受本机负载影响，原始与补充测量均保留，不据此验收完整系统帧率。

成本：[原始计时](../../runs/a1_sup_kidney_alt_20261028/performance.json)、[独立进程补充计时](../../runs/a1_sup_kidney_alt_20261028/performance_isolated.json)。精度始终使用PIL网格，两种预处理的用途不混用。
