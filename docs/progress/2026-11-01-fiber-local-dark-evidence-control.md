# 局部暗前段当前证据：三臂完整可行性对照

2026-11-01。**按冻结门槛，本轮局部证据方案未通过，不进入像素修正。** 已实现三臂，完成202张静态原输入新推理和三臂各完整2694帧、6独立进程8082正式帧。原分割和两份网络概率精确不变；没有新分割改善、训练、默认替换或结石S3。

本轮回答的是“已有神经杆体周边的当前RGB能否支持暗区候选”，窗口、边缘和采样点均为诊断，不是新增光纤掩膜。视频参考上发现少量可靠支持，但图像参考的一致性和性能均未通过；部分负例存在参考完整性疑问，不能把全部参考FP直接解释成真实物体误认。

## 实现与完整性

新增独立`fiber_local_dark_evidence.py`、实验入口和机制测试；复用T1.proposals，未调用其完整测量/门槛/状态，未改旧T1、T2-P、光度变换、模型或默认。最多两轴、每轴双端有界搜索，21个锚点须至少12个原高置信光纤支持；主比较固定三个横向点，不使用辅助自适应剖面替换抽样总体。颜色为同帧杆体/两侧局部色度对照，不跨帧保存或从验证视频训练共享模板。

局部支持同时需要当前双侧边缘以及至少2/3固定点满足可靠色度或原P≥0.1；只有对应点被标记。原P<0.1的暗区可以由当前RGB进入研究；极暗/低饱和高光颜色不可靠时保留未知。两端扫描不中途填gap，实例轴组歧义不强选，原结石冲突单独计数。没有断定真实末端、填圆帽或改变任何像素。

15项新机制测试、16项冻结提议/专家回归共31项通过；独立工程核验78项通过。静态实际只做202次两网配对推理供三臂观测共享；完整视频每帧都实际做两次前向，12帧预热/进程另记，共72预热帧。模型数2、参数49,202,790，权重/参考/源码身份与完整档案保留。

### 第1209帧：有少量证据，尚未解决主要暗段

人工整帧参考支持可见暗段遗漏，本帧全部光纤FN4002（其中低Lab组2626）。锚点有20个高置信点、9个有效侧点；另一轴不合格。搜索窗内FN2931、窗外1071；149个有效固定点中28个落在参考光纤，局部支持8点全落在参考光纤，其中5个原FN、2个原P<0.1 FN。该2点不代表恢复两像素，更不代表端帽/尖端已被定位。

对照板显示主固定剖面沿神经短段PCA方向偏离参考暗段，窗口虽覆盖部分目标，固定点仍大量落在旁边组织；侧边缘继续支持也稀疏。此为当前采样与语义参考的相对位置观察，未验证真实物理轴角。内部颜色/概率过渡仍只作标志，不把最强过渡当端点。

### 图像负例：当前参考不支持采用，实际归因仍有歧义

图像132的753个支持点只有74个与现有光纤参考一致、679个为参考非光纤；82张参考无光纤图像中，6张产生无歧义受支持假设：显示第45、63、67、85、101、129张。没有删掉这些样本、改成未知、改标签或放宽0.95门槛。

但对照原RGB可见至少部分争议样本有蓝色结构而参考无光纤，尤其第101/129张画面边缘，第67张亦有蓝色结构；不能凭颜色直接确认它们是真光纤，也不能把标签缺失问题当成已经排除。第45/63/85张还涉及底部/绿色高亮结构等不同情形。六例全部保留，后续需区分真误认、原标签语义/完整性与截屏/FOV域差异，而非预先全部归为算法FP或自动补真值。

![六张参考无光纤争议图：原图与原参考](../../runs/a1_fiber_local_dark_evidence_20261031/negative_reference_contact_sheet.jpg)

679个参考FP支持点中182个原本就为raw2光纤、277个原为背景、220个原为结石；其中74点原P≥0.9。这表明“当前高置信杆体”也不能独自证明身份；220个结石冲突保留诊断但未覆盖原结石。当前输出没有产生任何新增分割FP，以上仅是未来候选的风险。

标签坐标取最近像素，神经特征按浮点位置双线性采样；主统计的低P分组按去重原像素P2。另报双线性采样也低于0.1的保守核对：视频128个低P FN命中中127个满足，图像6个中5个满足；并非全部命中都能解释为纯颜色越过低P。二者均保留，不据结果重定义通过门槛。

## 决定与下一步

按冻结协议，静态拒绝项为image132支持Precision不足、参考无光纤出现无歧义假设；此外观测和总管线成本失败。视频上的高支持Precision与少量原低P暗段证据不能抵消这些失败，**不进入像素修正、不调阈值/范围/颜色模型或自动训练**。原默认A0、混合A0仅推理限制、521/132/144/29和当前70均不变，T2-P仍未实现，stone_new与视频派生物不训练，训练/144test像素读取0。

最小下一步是只读拆解失败：核对六张争议样本当前来源标注语义/完整性；按原标签与RGB分开列出身份误认风险；检查1209及其他失败中的种子轴/固定剖面与外边缘覆盖；分别分析采样、颜色特征和元数据成本。只准备必要的少量独立确认清单，不要求重做全量训练数据审核，不自动改标签。完成后才决定是否另立局部候选或训练协议，避免把当前高置信错误种子扩成更大的错误光纤。
