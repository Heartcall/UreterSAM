# A1-SSL 准备：训练专用备用池伪标签诊断

日期：2026-10-28。已完成 190 张监督图像与 800 张 kidney 备用图像的只读诊断，冻结了后续监督/伪标签短程对照协议。**严格筛选的光纤像素与来源标签一致度为 94.12%，未达到启动前固定的 95% 条件，半监督训练暂缓；S2 下一步准备替代骨干对照。**

94.12% 是训练图像上相对于暂定来源标签的条件一致度，不是独立精度或临床正确率；其余像素既可能是预测错误，也可能是标注边界或完整性问题。没有自动改标签、降低门槛、删除样本或要求重新人工复核。

## 范围与启动前冻结规则

- 活动监督清单保持 190 张 kidney 图像；800 张备用图像本轮首次用于只读诊断，仍未进入活动无标签训练池。
- 每张备用图像实际字节均与记录 SHA256 一致，800 个哈希互不重复，且与监督图像、验证帧没有精确哈希重叠；stone_new 已知图像哈希不在其中。该检查不证明病例独立或不存在近重复。
- 备用图像的标注不读取，所有备用标签统计保持未定义。两段视频只核对既有输入身份，没有生成其训练伪标签或更新参数。
- 教师仅来自此前干净 kidney 训练：单网30轮 seed42末轮作为主教师，两组15轮 seed42/123末轮作为辅助成员。没有使用 A0 或混合来源权重生成伪标签。
- 采用 PIL/256 网格、batch2，固定 seed；确定性的逐图光度增强沿用当前亮度、对比度、颜色和模糊范围，不改变几何坐标。全部模型使用推理模式，参数更新次数为0。

固定筛选为最大 softmax ≥0.95、归一化预测熵 ≤0.2。比较四种策略：单主教师；两辅助成员一致；三模型一致；三模型一致且主教师在光度增强后仍高置信、低熵、同类别。熵是预测分布的集中程度，不等于真实错误概率；同系列教师也可能共同犯错。

主策略在推理前指定为第四种。启动条件要求两前景类别分别满足：在暂定训练标签上的一致度 ≥95%、正类覆盖 ≥30%；备用池中保留 ≥2560 像素且 ≥20 张图像各有至少16像素；强增强后保留前景 ≥80%；接受像素中的背景比例 ≤98%。这些只是保守研发筛选条件，不是经过临床校准的门槛。

## 已冻结但未启动的短程协议

[train_a1_ssl_kidney_pilot_20261028.json](../../configs/train_a1_ssl_kidney_pilot_20261028.json)明确标为 `DEFERRED_READINESS_FAILED`、不可执行；它是协议，不是已实现或已运行的训练器。

后续满足准入条件时，两个实验从同一纯 kidney 主教师权重开始，重置优化器和随机状态，各训练5轮、每轮95次更新，学习率1e-5；一组只监督，另一组只增加固定稀疏伪标签损失，系数从0.02升到0.1。保留背景监督，限制无标签背景占比，没有前景的无标签批次跳过该项；不同时加入互学习和交叉学生伪标签。

协议固定了非有限损失、输入身份变化、持续前景退化、相对同轮监督对照的光纤 Dice下降超过0.02或结石Recall下降超过0.05持续两轮、伪标签类别长期消失等停止条件，不自动超过5轮。旧半监督入口会同时开启多种训练项，不冒充本协议的单因素对照。

本轮未创建活动无标签训练清单，没有训练伪标签集，也没有加载新优化器。`diagnostic_masks` 仅是诊断产物；未自动提升为训练数据。不得将协议中的计划预算计入已完成训练。

## 当前决定与下一步

A1-SSL 准备任务完成，实际半监督训练暂缓。这一结论不证明半监督方法无效，只说明当前教师、标签依据和固定筛选规则未通过本次研发准入条件。
