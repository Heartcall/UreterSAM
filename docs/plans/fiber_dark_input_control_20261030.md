# 暗色前端：固定光度输入响应对照

2026-10-30，v1。**协议已制定；输入变换、模型推理实验、分割修正和训练均尚未执行。** 承接主计划v2.20，先判断固定光度输入是否能让现有网络重新支持暗段。原T2-P仍为未执行的局部边界对照，不放宽其概率保护或半径。

## 要回答的问题

[只读证据](../progress/2026-10-30-fiber-dark-appearance-observation.md)显示：video_2第1209帧参考包含的可见暗蓝前段在原网络中已低概率，低亮组FN2626中2521的P_fiber<0.1；T2-P只能接触105个。该现象不能通过窄边界平滑全面解决，也不能靠填理想形状验证真实可见尖端。

本轮只问三件事：固定提亮能否提高这些原低P像素的光纤证据；是否同时增加亮斑、组织、腔壁误检或伤害结石；保持颜色比例与改变颜色比例的两种输入是否表现不同。结果不自动证明照明的因果作用，更不是训练增强不足的唯一证明。

## 当前实现与增强核对

当前推理先将原BGR转RGB，经PIL双线性缩到256，再按ImageNet均值/标准差归一化。old190结石专家与A0 model1光纤专家各运行一次，分别三类softmax、FP32双线性映射回原图，结石argmax=1后光纤argmax=2覆盖。

已核对当前`ureter_semis/data.py`及`supervised_trainer.py`/`trainer.py`的实际调用：有标签`mode=train`只走同步水平/竖直翻转；无标签路径在几何弱视图副本上调用`_strong`的亮度、对比度、饱和度及随机模糊；`mode=val`不走这些增强，native验证也单独处理原图参考。不能因存在`_strong`就宣称有标签已接受同等光度增强；来源导出预生成增强和运行时增强仍应区分。以上是当前路径核对，不能直接反推A0全部历史训练，更不据此自动重训。

## 三臂与固定变换

| 臂 | 结石输入 | 光纤输入 |
|---|---|---|
| raw2 | 原图256张量 | 同一原图张量，精确复现 |
| fiber_vlift | 原图256张量 | RGB共同缩放的V提亮 |
| fiber_channel_gamma | 原图256张量 | RGB逐通道Gamma |

两变换固定gamma=0.7，属于预先指定的一项工程假设，没有变换预览、结果或验证拟合用于选参数。禁止gamma扫描、每帧自适应曝光、按视频统计归一化、CLAHE/Retinex、新颜色模板或挑选最好一臂输出。

变换在**原PIL RGB双线性缩放之后、ImageNet归一化之前**应用于float32 RGB，不转回uint8、不二次缩放、不变换原始评价图像或GT。

- 共同缩放：v=max(R,G,B)，v>0时C_new=(C/v)×v^0.7；v=0时保留RGB0。三个通道使用同一比例，保持归一化RGB色度，白/黑端点不变，仅夹紧浮点舍入误差。
- 逐通道Gamma：C_new=C^0.7，三个通道分别计算。

两者的最大通道值均为v^0.7，但**Lab亮度、感知亮度和局部对比度不严格匹配**。因此比较只能解释为“同V目标下两种RGB表达的不同网络响应”，不能把差异全部归因于色相或照明。这不是相机辐射校准或真实曝光重建。

每帧仍只有两个权重实例和两个网络分支前向：原结石一次、对应光纤输入一次。raw2共享原张量；变换臂额外所需的张量准备/传输如实计时。没有第二次原光纤前向、TTA、原概率取max、历史概率查询或缓存掩膜保护。可在离线评估中比较原预测，但它不能进入候选推理。

**结石概率必须精确不变，最终结石掩膜可能变化。** 新光纤预测依旧具有类别覆盖优先级，可能覆盖原结石，也可能丢失原高置信正确光纤。这轮输出是诊断掩膜，不能宣称保护了所有原正确像素；所有损失通过既定门槛和绝对计数审计，默认输出保持原样。

## 暗段、杆头与几何的分离

亮度分组始终按**原图**Lab L编码与HSV V的[0,85,170,256]固定区间；不能从提亮图重新分组，以免把暗段挪出暗组。统计所有语义光纤像素及距GT边界超过3×min(H,W)/400像素的内部子集，同时报告每帧、两病例、来源与曝光分组。

重点记录原FN中P<0.1像素的概率变化、恢复TP与新增FP；提亮有可能帮助暗头，也可能增强气泡/组织/亮斑。独立展示杆体到暗段的过渡和真正可见末端；没有端部参考时不把任一最大颜色梯度、概率下降或PCA最远端自动命名为头部。

T1在1209帧没有合格当前观测，入口方向和搜索范围本来就可能失败。本轮不把新概率送进T1重新拟合，不扩大其端部窗口，不把新结果声称为几何改进。若光度输入能恢复暗段证据但全局质量失败，才另立“杆体与暗端不同外观、当前图像候选与软几何”的局部协议；几何只给候选，当前RGB仍须支持可见像素。

## 验收和停止

原`compare_two_network_experts_20261029_v2.json`的29帧门槛及70/132八项结石/光纤Dice、Precision、Recall、边界F对冻结classwise3的不退化检查保持；同时对同轮raw2比较，epsilon1e-12。只有暗段更完整但组织FP、结石或边界退化，则拒绝。

额外条件在运行前固定：

1. 原图Lab低/中亮组有GT时，70、132及每视频病例光纤TP均不低于raw2；空组不可计算，不能记通过。HSV分组另报，不替代Lab分组。
2. 每类/每集合粗删除TP≤floor(0.001×原TP)、净TP不下降；每帧删除TP≤max(1,floor(0.005×GT类别像素))，保留全部违反帧。
3. 要称通过暗光纤开发目标，还须70、132及固定1209帧的低Lab组FN都严格下降，并通过上述质量与完整管线预算。该定义是暗色语义像素改善，不是尖端准确率或照明因果。
4. 每帧三类概率合法、坐标不变，权重/原标签/源身份不变，raw2原图精确复现，结石概率精确不变，全部6进程完成；原高置信正确像素的变化也要单独列出，不能隐藏。

两个固定变换都失败就保留负结果并停止，不换gamma或增加增强后再宣称通过。若只提升概率/Recall却增加FP，也拒绝全局变换，记录它提供的外观敏感性线索；若没有提升，仅否定这两个固定变换，不能否定全部亮度假设。即使通过，也不自动采用model1、替换默认或进入结石记忆。
