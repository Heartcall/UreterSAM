# T1：低成本当前图像观测与历史辅助搜索

2026-10-30，v1。**方案和机器配置已冻结；T1实现、推理实验尚未执行。** 本步承接主计划v2.16的方案制定，不修改分割、旧状态器或默认模型，不训练。

## 由T0结果限定新假设

[T0完整对照](../progress/2026-10-30-fiber-temporal-state-control.md)已完成10776帧，不能重复称为未执行。其主要发现：

- 新状态器只需约0.12ms，但当前全图FOV/密集边缘/端帽拟合中位约17–18ms，新总管线p95达49.75/47.11ms。仅换滤波器不能解决实时性。
- video_2显示439–440帧，当前RGB和观测已支持新光纤位置，新门控仍停在旧位置，441才确认；643帧也保留明显新旧状态分离。拒绝跳变不自动等于拒绝错误，固定三帧等待可能延迟真实移动。
- 有状态帧video_2旧1377、新1369，另有一次非法外推清空。低抖动、预测覆盖、对当前拟合残差不是几何真值准确率。

因此T1只检验两项可分离假设：**少量当前图像采样能否以明确预算提供可用几何观测；在当前证据不足时，额外一个历史姿态候选是否有增益。** 当前强证据优先，历史只能帮助搜索与弱观测验证，不能强迫当前服从旧位置。

**本轮仍不改任何可见分割像素。** 候选、观测与状态单独导出；不裁模板、不删组件、不填隐藏轮廓、不用历史把蓝色补成光纤。T1如果通过机制/成本，也不自动获得分割改善或像素融合授权。

## 有界当前候选

将当前原图光纤概率用面积插值缩到160×160，在同网格估计当前FOV。以P_fiber≥0.2产生八连通种子，少于4网格像素的种子只是不产生几何提案，原掩膜不受影响。向量化计算各组件当前概率质量，按质量、组件标签排序取最多2条轴线，用加权PCA和2/98投影分位数生成初始范围；每轴最多2048个确定性均匀采样支持点。

组件只提供轴线种子，不代表实例身份，也不是“保留最大入口组件”的可见掩膜过滤。每条轴可在有界走廊内收集其他组件的当前支持点，允许同一根光纤被遮挡后形成断片。走廊法向半宽为初始组件宽度的0.75倍加4像素（400基准），轴向最多扩0.10倍图像对角线；不填没有当前支持的空白。

入口方向暂由两端到当前估计FOV边缘距离判别，差小于0.02D时记录方向歧义，只输出无向杆体证据，不强行宣称入口/尖端完整位姿。历史可为弱候选消除方向符号歧义，但不能因此把它升级成独立强当前证据。内部工作通道入口、截图留白和错误FOV会造成失败，必须记录，不把FOV当真实设备标定。

所有提案参数在本方案中固定；这些是工程假设，不是用视频估计的共享形状/颜色模板，也没有根据GT选种子或窗口。当前候选排序不加历史/入口奖励，避免历史先决定“哪里应该有光纤”。

坐标用像素中心映射：原图x=(网格x+0.5)W/160−0.5，y同理；先转原图坐标再PCA/宽度/残差判定。方向启发的网格FOV距离乘min(H,W)/160只作显式近似，非等比例图像不能把它当精确物理距离。RGB/概率采样若所需偏移越出原图，则该点不支持边缘，不能把补零当黑色边界。

## 轻量杆体与端部观测

每轴只在可见范围10%–75%处取8个横截面，每侧17个有界搜索位置。直接对原RGB做双线性采样，以法向两点RGB差的归一化L2作为颜色边缘，取消全原图Sobel和旧24截面/多端帽枚举。搜索半宽在400基准4–12像素之间、按局部宽度0.25倍确定；位置间距与图像尺寸明确换算，不能把160网格坐标误作原图坐标。

同一横截面两侧都须有当前颜色对比度≥0.04；不要求固定蓝色、饱和度或相同亮度。缺少当前支持的截面不虚构边缘。至少5/8对支持、两次鲁棒直线迭代、正宽度、固定线残差和宽度族检查后，才形成杆体观测。0.04是新RGB差分度量的工程阈值，与旧Sobel的0.04不是同一标定量；不在看完验证视频后调整。

端部单独用中心及±四分之一宽度的3条轴向剖面，在种子末端附近±12像素（400基准）、各25点搜索当前RGB/概率过渡。得分为颜色对比度加0.25倍正向网络概率下降；颜色对比度≥0.04或概率下降≥0.15才算支持。要求中心和至少一侧有效，过渡位置跨度不超过当前杆体远端宽度。

这是**可见前沿候选**，不拟合固定圆/椭圆，不估计真实端帽半径，也不把遮挡边界自动当解剖尖端。允许浅色、白色和低饱和端部；没有证据就输出“端部未观测”，不因杆体仍蓝色就删掉或缩短光纤。T0的端帽轴比本轮不估计，不能给出从未测得的圆钝端帽参数。

## “当前证据充分”的明确含义

候选评分只由当前图像/网络计算：`q=0.4qN+0.4qE+0.2qR`。qN是8截面内部采样点的平均光纤概率，qE是双侧支持对数/8，qR是按固定容差归一化的线残差指数。它不是光纤身份概率或校准置信度。

- 强杆体：有效几何与至少5对边缘、残差通过，平均光纤概率≥0.5，内部光纤argmax占比≥0.75。方向、端部各保留独立有效标志，强杆体不自动等于强完整尖端。
- 弱观测：同样须满足当前双侧边缘/几何，平均概率≥0.10；只能在已有兼容历史时更新，不凭单次弱观测初始化完整位姿。
- 两个合格当前候选分数差<0.10时标记歧义，不因“最多一根光纤”而强选一个。没有当前支持的历史候选不能进入评分胜者。

歧义前先消除“同一支持点产生的重复提案”：最多两条当前轴在全部支持网格ID集合IoU≥0.8、无向轴夹角≤5°时，只保留当前证据分数高者，再按组件标签打破并列；不补第三条轴。这只合并提案元数据，不合并或补齐分割片段。内部概率在全部8×3个有界位置采样，不能只统计边缘通过的高概率截面；至少5个截面三点都在界内，记录分母和缺失，避免条件选择美化证据。

本轮不新增蓝色概率模型或颜色加分，也不让神经网络高概率单独证明身份；过去已有高置信参考误检。RGB差分只提供边界证据，亮组织也可能产生边界，错误初始化/持续错误仍可能通过，不能提前保证可靠。

## 更新顺序与部分观测

新状态采用六个联合图像参数：入口ex/ey、轴角、长度L、入口宽w0、前沿处线模型宽w1；派生前沿=e+L·u。w1不是真实圆钝头直径，未观测的端帽轴比不补默认真值。

先评价独立当前证据，再考虑外推与几何跳变：

1. 强、无歧义当前字段在本帧初始化；若与预测兼容沿用alpha0.65/beta0.10，明显越界则本帧接受测量并清零对应速度。**没有固定三帧等待**，非法外推不能压过同时存在的强当前观测。
2. 弱字段只在与有效历史兼容时按同样增益更新；保留旧的0.08D位移/0.10D长度/20°/宽度比[0.5,2]作弱观测门槛。只检查双方都有的字段，记录未检查项；不因连续出现而自动升级成强观测。
3. 杆体组与端部组分开记录是否观测、年龄和有效性。端部不见时不把组件末端当短光纤；端部组最多预测3帧，之后端部未知，当前杆体仍可有效。用当前杆体加预测长度得到的前沿仍标为预测。
4. 无当前证据时只保留有限历史，组预测非法就清除该组；不丢弃另一组的有效当前证据。来源/尺寸/时间异常清空，静态图逐张初始化，历史不跨视频或图像。

此更新规则仍可能过于信任错误强观测，或把真实弱观测拒绝；必须完整报告。当前T1不加入光流/相机运动网络，当前强证据优先同时适用于镜头或光纤移动，但不能据此声称已区分二者；必要时以后单列相机运动假设，不能在本轮静默加分支。

无向杆体线可作为原始观测独立导出，但不等于有效入口/轴向状态组，不能初始化或覆盖ex/ey/θ；用历史确定方向后只算弱观测。这样不会把“杆体可见、方向不明”伪装成完整位姿。

## 历史辅助搜索的唯一增量

history_search臂每帧仍运行全图当前提案。只有没有无歧义强当前胜者、且存在未过期预测杆体时，才增加最多1条历史走廊；围绕预测轴和宽度采样当前图像。端部搜索必须有未过期的预测端部，不能从“应有端帽”制造端部证据。

历史候选用与当前候选完全相同的RGB、网络与几何规则评分，始终标记history-conditioned，只允许作为兼容弱观测更新。历史不能加分把缺少证据的位置变成强当前证据，也不能排挤已存在的强当前胜者。没有支持则拒绝、增龄或过期。全图当前候选始终保留，过期/初始无种子不能靠凭空几何修复。

与过去方案的实质区别：不把理想形状与掩膜相交，不删除游离组件，不全图固定模板定位，不复用重网处理裁剪，也不无条件固定三帧确认。每个增量由light_current→evidence_state→history_search逐项对照。

## 计算预算、数据与评测

每帧最多2个当前轴、1个历史轴；每轴8横截面、每侧17位置和3×25端部采样，PCA支持点上限固定。禁止旧密集拟合器“兜底”、额外网络/裁剪、全原图梯度图和无限候选搜索。以操作数量约束开销，不按机器负载临时截断候选而改变输出。

额外几何阶段p95设计目标≤5ms；这是启动前的工程目标，不能把它与粗网p95相加推导总管线通过。**每片实际总管线p95仍须直接测量并≤1000/FPS**。失败也完整测完，不按结果放宽采样、阈值、权重、TTL或候选数。

- 数据冻结为70视频参考+132图像，保留原29/新41、43/27病例、来源68/64与曝光25/107；202张新原图复现可共享相同各臂掩膜，不虚报多次静态前向。
- 四臂各自两片完整独立新进程：722+1972=2694帧/臂，8进程共10776帧，batch1/FP32，12帧临时状态预热后清空。静态或成本失败不免测。
- 时间用验证后的源PTS或全段声明frame_index/FPS；70稀疏参考的状态从完整回放真实索引取，不串成相邻帧。静态图无历史候选。
- 保存全部候选和拒绝原因、qN/qE/qR、方向/端部/歧义标志、强当前覆盖历史、弱观测更新、历史提案/接受率、每组年龄及耗时。四臂同样传原图掩膜和两份三类概率，记录CPU/GPU开销与完整含导出周期。
- 两段完整对比、参数曲线、失败板保留所有方案。T0的439–441、643、622帧列为开发回归片段，逐项解释当前证据是否达标；不能强制其成功或据此改阈值，更不是独立最终测试。

所有分割Dice/P/R、边界F及TP/FP/FN必须与原model1完全相同；TP删除或恢复、FP增减均0。几何可用率、前沿候选、预测覆盖和轨迹平稳仅为诊断，无独立尖端真值不报尖端Recall/定位误差。70是重复开发参考，42/120随机样本不完整，不外推全片精度。静态445像素无种子样本不能借其他图像/视频的历史修复，也不保证此轮端部候选能恢复其识别。

## 测试、停止和实施顺序

后续新增观察器、证据状态器与独立运行入口；旧T0源码与结果不动。先验证网格/原图坐标、空种子、边缘采样、断片不填充、候选上限/并列确定性、歧义、白/低饱和端部与反光干扰、端部缺失不缩短、强当前骤变即时覆盖、非法预测不挡强当前、弱观测兼容/过期、部分组有效性、静态隔离与因果前缀。合成样本有解析边界，仅验证机制，不能代替真实准确率。

然后202原图复现→四臂完整两片→独立审计→按冻结门槛收尾。运行前保存源码、配置、模型、输入身份与归档；现阶段仅归档方案，没有冒充已完成的模型测试。

若出现原掩膜改动、未来/跨病例状态访问、隐藏轮廓填充、无当前支持却接收历史候选，判为实现失败；修复代码后另存失败与新结果。若候选/歧义/成本假设失败则保留负结果，不扫描阈值或直接进入T2像素修正。

无训练、默认采用或结石S3；stone_new排除、视频及派生物只验证、原521/132/144/29和活动70标签冻结，本轮不读521 TRAIN或144保留test像素。Godot参数不作真实标定。任何训练仍需单独的数据/合规初始化/实际增强/预算/验证/回滚计划和批准。

回滚通过不接入默认入口实现：只运行新实验命令与新目录，关闭即回原默认A0；model1也未因本轮被采用。**最小下一步是实现这四臂有限T1对照，先检验轻量观测和当前证据优先，再检验历史搜索是否提供额外价值。**
