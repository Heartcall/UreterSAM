# 光纤时序几何状态与异常观测对照计划

2026-10-30，T0 v1。**本文件与配套配置已完成；实现、推理实验尚未执行。** 用户提出相邻帧光纤长度、边界方向/夹角和末端坐标应连续，随后要求按计划继续。本步将该观察纳入原“全图保底、空预测与结石保护”方案设计，不启动训练或直接改分割。

## 目标与证据

先验证一个可被独立检验的机制：**单帧不可信几何跳变不应立即覆盖历史状态；持续有图像证据的真实移动应能重新定位。** 短暂漏检时允许预测搜索位置，但预测几何与当前可见像素必须分开。

已证实的实现与结果：

- [现有跟踪器](../../tools/fiber_shape_prior.py)维护入口、方向、长度、两端宽度、端帽比例及速度，使用常速度alpha-beta更新；超过尖端/长度/方向/宽度门槛时立即以新观测重置。因此它是平滑器，并没有持续拒绝孤立异常观测。
- [旧运行管线](../../tools/run_fiber_shape_control.py)随后调用`visible_fiber`：几何栅格与当前网络支持相交。历史29帧原光纤Dice0.9668，几何0.9553、因果几何0.9556。因果版相对静态仅净补76个TP，不能抵消整轮廓裁剪损失。不能以该结果断言时序约束无效，也不能宣称换跟踪器即可提高分割。
- [最近ROI诊断](../progress/2026-10-30-fiber-refinement-feasibility.md)发现视频70帧误差可被局部窗口覆盖，但图像445个FN无种子、保护结石锁住85/523个GT光纤像素、重网裁剪代理超时。时序预测不能修复独立静态图像、凭空生成低概率光纤或自动解决类别保护冲突。
- 当前无独立解剖尖端/方向真值，几何平稳、掩膜稳定和物理尖端正确是不同结论。光纤快速伸缩、镜头移动/旋转、出入视野和遮挡都可能引起真实跳变，连续性是有失效条件的软先验。

本轮用model1两网作有限实验底座，三网classwise保留冻结质量参考。model1仍未采用，先前严格替换检查失败仍有效。本轮不搜索更多成员。

## 联合几何状态

沿用已存在的七维二维外观状态，减少首轮变量：

`z = (入口ex, ey, 轴角θ, 伸出长度L, 入口宽w0, 末端宽w1, 端帽轴比ρ)`。

加上同维速度，用真实视频时间步预测。角差统一wrap到[-π,π)，长度/宽度/端帽几何必须有限且为正。

可见末端候选由`tip=e+L(cosθ,sinθ)`推导，不另行独立平滑。杆体到端帽中心长度`Lc=L−ρw1/2`；在Lc>0时，以`atan2(w0−w1,2Lc)`计算有符号半收敛角，两侧方向也从同一状态导出。避免入口、两边、长度和末端分别平滑后互相矛盾。两边延长线的交点不是圆钝末端，以上是像素外观几何，不是设备标定或物理激光落点。

第一轮不引入Kalman协方差或声称概率校准。记录观测支持、创新量、预测年龄和丢失次数即可；这些不是几何正确概率或置信区间。以后只有证据支持才加复杂不确定性模型。

## 四个固定对照

| 臂 | 当前观测 | 历史更新 | 可见分割 |
|---|---|---|---|
| raw2 | 不拟合 | 无 | 原model1掩膜 |
| current_observation | 现有原图FOV/双侧边缘/端帽拟合 | 无 | 原model1掩膜 |
| legacy_state_only | 同一拟合器/设置 | 原alpha-beta，大跳变立即重置 | 原model1掩膜 |
| gated_state_only | 同一拟合器/设置 | 创新门控、异常暂存、连续确认后重定位 | 原model1掩膜 |

**所有臂分割逐像素保持原样。** 不调用几何掩膜栅格化/相交、组件删除、颜色硬门控、裁剪精修或历史像素填充；几何只导出为独立参数和覆盖图。这样隔离“跟踪策略”与“模板裁剪”，不把平滑后的形状冒充分割改善。

同一当前帧拟合器仍可能选错候选、依赖某个组件或被遮挡打断。这些局限不在T0暗中修复；记录组件/入口选择和拟合失败，不先假定最大或入口附近组件就是真光纤。一个实例可以有多个可见片段；本轮不因此删除或强连片段。

## 门控、确认与失效规则

首轮固定原alpha=0.65、beta=0.10，以及旧门槛：尖端偏移0.08倍图像对角线、长度偏移0.10倍对角线、轴角20°、宽度比[0.5,2]。这些较宽的工程门槛不是设备物理上限，也未证明最优；首轮保持相同，专门比较重置策略，不能看完视频后再收紧。

| 当前情况 | gated_state_only行为 |
|---|---|
| 首个有限、有效拟合 | 初始化；没有历史时无法认证首次观测是否正确 |
| 观测与预测符合全部门槛 | 按原alpha-beta更新，清空可疑分支 |
| 单次越界但当前拟合有效 | 不更新活动状态；暂存观测，输出带年龄的历史预测，原掩膜不动 |
| 连续3次越界候选互相一致 | 当前时刻确认重定位，速度清零；不回改前两帧，不用未来帧 |
| 可疑候选不连续或拟合缺失 | 打断连续确认；候选不一致从当前样本重新计数 |
| 连续缺失/拒绝 | 最多3帧预测，第4帧清空活动状态；独立记录无观测，不画成可见分割 |
| 视频/来源/分辨率改变、时间不单调或间隔>0.5s | 清空活动与可疑状态；不借用别的病例或静态图像历史 |

待确认候选的连续性用同一组门槛，前两观测建立候选速度后可作常速度预测；不新增第二套凭视频调参的几何阈值。正常观测重新匹配活动状态时，取消可疑分支。先评价本帧确认再处理旧状态到期；即使旧状态已清空，只要仍有待确认序列，也不能借“未初始化”绕过三次确认。

三次确认意味着真实骤变可能延迟两帧才被状态接受；必须报告这个取舍。大跳变不是错误标签，状态拒绝也不是证明预测错。第一轮不额外引入场景切换/光流模型；显式片段边界和时间异常重置，未检测到的镜头骤变是已知风险。

## 全图保底、漏检搜索与结石保护

T0始终运行全图两网，输出其原掩膜；几何失败、跟踪过期或确认中也同样回到这一输出。当前帧无光纤证据时，历史只能提供未来搜索位置，不能写一段光纤、隐藏轮廓或虚构尖端。

**历史辅助搜索T1只作后续条件项，不在T0偷偷加入。** 若T0机制与成本值得继续，再单列固定协议：历史预测限定当前帧搜索范围，候选由当前网络概率/双侧边缘/局部对比度产生，比较无历史与有历史的候选排序；预测区域本身不能充当候选证据，不能把扩大区域等同召回提升。初始无状态、过期、快速移动必须保留全图搜索与明确拒绝路径。是否需要重新拟合、局部图像观测或网络调用，届时单独冻结预算，不直接沿用已失败的裁剪代理。

结石保护冲突在T0通过“完全不改掩膜”避免新增，但85/523个既有冲突仍在。T1若只输出搜索/几何状态也不能声称恢复这些像素；任何实际像素融合必须另列显式结石优先/光纤覆盖冲突的对照与逐类TP损失检查，不能通过偷偷重组类别得到改善。

2. 先做解析合成轨迹与因果性测试；只验证机制，不用合成例子标定设备、训练或宣称真实几何准确。

4. 四臂各自两个独立新进程，完整video_1 722帧、video_2 1972帧，共8进程10776帧；拟合或成本失败也必须完成。预热12帧使用临时状态，正式帧0前清空。真实可靠PTS优先，否则全段声明frame_index/FPS；不用处理速度作dt、不静默混用时间基准。
5. 逐帧验证RGB/原掩膜身份、状态更新和来源隔离。保存观察与预测、末端/两边方向、创新、拒绝/确认/重置原因、年龄和耗时；导出两段完整同步对比。几何叠加须明确标记observed/predicted/unavailable，不能用颜色暗示预测已被验证。
6. 独立审计后报告所有成功与失败，按冻结规则停止或另提T1。无训练、默认替换或结石记忆S3。

## 指标、门槛与停止

分割：结石/光纤Dice、Precision、Recall、边界F和TP/FP/FN必须与同轮原model1逐像素相同；原TP删除、新增FP均应为0。中心线覆盖若复用既有代理也应相同。原29门槛、132/70不退化规则和三网参考不变；相同分割不是质量提升，也不自动解决model1未通过严格替换的问题。

状态：报告当前拟合可用率、仅预测率、无状态率、异常拒绝、待确认长度、重定位/超时/源切换重置次数；记录参数速度/加速度、尖端位移和观测残差的分布。少跳动可能只是冻结错误状态或反应慢，不作为准确率验收；未运动补偿的邻帧IoU同样只能作诊断。

性能：同轮raw2重测，分别计两网预处理/前向/原图概率与掩膜传CPU、FOV/拟合、状态器、总管线与含解码/绘制/审计/导出的完整周期。独立进程p50/p95/max、实际网络与参数量、CPU/GPU开销均记录；不相加或相减分位数。生产候选仍要求各片管线p95不超过各自源帧间隔。旧拟合曾平均14–15ms，可能主导成本，不能因状态向量小就预告整体实时。

停止条件：任何未来帧访问、跨病例/静态状态泄漏、原掩膜改动、预测几何被写成可见分割、源码/权重/输入身份改变，均为实现失败，修复后另存结果，不选择性丢帧。成本不达标仍完整回放、保留失败；不调门槛、确认数或TTL使其通过。T0最多四臂，不自动执行T1、训练、新网络头、颜色融合或默认采用。
