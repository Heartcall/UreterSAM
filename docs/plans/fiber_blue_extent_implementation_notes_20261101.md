# 蓝色外边界候选：实现澄清与合成机制记录

2026-11-01，真实202静态/两片视频新候选实验之前登记。原数值配置与执行协议不改，本说明补充离散计算细节；没有读取新候选真实验证结果来改参数。

颜色各约束的带符号余量取最小值，余量>0表示当前像素兼容。另要求离中性色度向量范数大于传播噪声，避免近灰噪声被除法放大；没有新增V亮度门槛。65点外边界在相邻正/非正余量之间线性插值定位零交叉，不将内部最大RGB梯度当边界。

合成测试初版采用相邻采样点中点定位，会产生亚像素中心跳变，在直杆上也触发冻结的曲率约束。修正为上述色度余量零交叉插值后，直杆暗蓝延伸可被覆盖；没有放宽冻结角度、曲率或颜色阈值。另修正反向搜索初始两侧顺序及下一中心出图判定。锥形栅格边缘仍可能触发严格曲率回退，作为已知局限保留专门测试，不调参消除。

每一步沿实际中心位移，以≤1s的间隔检查当前RGB三条轴向见证线（法向偏移[-.15,0,.15]较小局部宽）；普通每站至少2/3、弱边3/3颜色支持，否则立即停止，防止横截面步长跨过黑隙。最终原图4连通与原结石屏障仍独立执行；不因采样线通过就填多边形。

种子外边界线性拟合只使用实际强侧点，一侧至少3点才有拟合；所有可拟合侧都须满足RMS，至少一侧可拟合。单侧弱段若先触发更严曲率/宽度拒绝，不需要等到2段上限；历史只使其具备资格，不能豁免形态约束。强当前不依赖旧历史接受。

没有正新增像素也检查末端。未定向的两端只保留状态；非远端不输出xy。半帽/黑隙/范围结束/原光纤继续/原结石接触均不能凭颜色结束强行给确定尖端。该实现不声称所有真实高光/白色端帽都可被恢复。
