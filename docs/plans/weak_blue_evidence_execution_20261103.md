# 多级蓝色证据与有界远端恢复：执行前冻结协议

2026-11-03，任何新真实数据结果前冻结。研究输出独立保存，不改默认、训练、标签、历史结果；不训练。

## 可证伪假设与四组

H1：旧颜色取硬条件最小值及4连通截断了具有当前RGB证据的暗蓝区域。H2：沿当前两侧角平分线/局部中心线，真实证据8邻接可恢复远端，且能观察外部终止；H3：在恢复完成后，以该前沿约束椭圆帽，可改善实际栅格形态。不得仅用模型曲线光滑支持H3。

固定四组：原connected_blue_union、原bisector_guided_blue_tip、weak_blue_extension、weak_blue_extension_tip。前两组与历史逐像素一致；后两组共用完全相同的证据/生长/尖端观察，唯一差别为帽及微小凹口证据内修整。全部四组独立进程运行722+1972帧；另202静态共享网络前向和70因果参考抽取。每进程12预热后清空状态。不因质量失败少跑视频。

## 机制

当前可信唯一杆体的色度和背景建立自适应证据。归一化RGB色向余弦、蓝相对背景优势、到杆体/背景色度距离差分别归一化，计算连续分数；暗色观测按量化噪声可靠性减权。强蓝沿用旧严格结果或高分；弱蓝必须有蓝优势/色向与局部背景距离或RGB边缘支持；不确定不能成为连接路径。黑色/近中性/石头不能成为蓝色路径。无固定蓝色亮度阈值，无共享视频颜色模板，无网络概率限制。

完整原B与可信核心为种子。沿两侧角平分方向或局部中心线，搜索旧B前沿外最多min(80px,图像对角0.2)，侧向为B稳健宽度1.75倍+8px的宽走廊，前方范围固定；允许有证据8邻接对角连续，永不填补不存在的像素。无逐截面宽度/曲率整段否决。面积保护沿用原0.25/0.1预算，预算失败回退union。原B、union像素及石头保护。记录未连接弱蓝、走廊外、石头阻挡、面积预算等阶段计数。T1只记录当前方向/异常截短一致性，不生成像素。

远端在完整恢复体8px带内选连续像素团（非单个最大值），最小面积6、跨度2、前沿3像素；单刺超过q90两像素不可确认。团不足为弱候选而非强行确认，需区分：已确认当前RGB外终止、弱候选、未知/遮挡/出视野。终止使用内外蓝证据分数下降及RGB或色度对比，前方孤立弱蓝不等于蓝色继续；连续路径真正触及搜索界则unknown。无外边界或前方黑暗不能输出确定点。理论交点不输出。

仅tip臂拟合固定4接点×4椭圆形状：端帽轴向顶固定真实蓝色前沿，两侧用恢复体鲁棒侧拟合，RMS≤1.5px、模型接缝≤15°、当前RGB边界支持≥80%、实际弧匹配≥80%；新增像素须本身已是可达颜色证据。绝不删原B或union，未知/失败保留完整可见候选。接受模型、实际帽像素改变分别记录。无证据加帽和帽顶外延均禁止。

## 评价与冻结停止条件

主要：全2694及焦点60帧每阶段暗蓝/低P新增量、杆体/远端像素数、投影长度增加、强弱证据/RGB边缘支持、保留率、异常增长、三态尖端、拒绝原因；几何沿用上一轮固定测量：侧HF减少≥15%、实际帽转角减少≥10%、实际接缝p95≤15°、RGB支持下降≤2百分点，union保留100%、原蓝前沿不丢。新弱蓝恢复是代理证据，不能作真实Recall。焦点确认≥50%及可观测帽覆盖≥25%沿用，不放宽。任一安全不变量不满足即不采用。低P/暗段语义TP/FP/FN、Dice/P/R/边界F以及132来源分组和70逐帧仅诊断；不完整标注不得被当成合理恢复的唯一否决理由。

新臂在全视频恢复像素为0、或没有增加远端范围，则H1/H2未被支持。出现可视明显组织泄漏，或未知区跨越、石头覆盖、无法解释的新增像素即不采用；保留最大增长8帧及全部焦点图供人工审查，不声称自动排除了全部身份误认。H3用实际像素测量，帽没有实际改像素不算轮廓改进。

独立进程测两网+后处理P50/P95，后处理目标5ms/源帧预算；导出实际吞吐并区分审计写盘耗时。实时目标不满足单列失败。无独立尖端GT，任何确认率、位移和可见蓝色投影长度均不称物理端点准确率。70/132已参与开发，无参考的全视频帧不计算准确率。禁止读训练521和保留test144组像素，stone_new继续排除，视频不训练或模板标定。
