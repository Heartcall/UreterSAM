# 实现细化：真实数据运行前冻结

协议不改数值。连续score = (0.40色向归一分数 + 0.35相对蓝优势 + 0.25杆体/背景色差归一分数) × sqrt(1-noise/max_noise)，各分量裁到[0,1]。身份须有正蓝优势、局部背景优势、色向和非中性色度；距离或RGB梯度作独立支持。强弱分数固定0.70/0.40。原严格B保护，强色图记录score等级，旧B不重新强制分类。

主体图：只有强/弱像素及已接受B走8邻接，不确定像素不连接主体。帽修整：为避免“所有可达强弱已经被union，所以后处理恒为零”，允许在恢复体边界1.5px内、原始图像仍有蓝身份且独立梯度≥0.012的不确定边缘像素作为局部帽凹口证据；它们不得用于向前搜索，不得越过已观察最远前沿，仍须根连通、椭圆内、石头保护及既定弧支持/接缝验收。不对无蓝身份像素填充。单独cap_boundary_evidence/cap_fill记录，便于否证。

score图按0..255量化存储仅用于审计，不参与算法；图层记录sum是量化质量而非像素数。所有其他层0/1。原控制两臂新增层为零，不改变其原输出/元数据。新扩展和新帽臂相同增长、同尖端观察；帽臂仅多一次恢复体局部双侧鲁棒切线和16固定椭圆求解。
