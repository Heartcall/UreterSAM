# UreterSAM 分割、对象记忆与几何辅助实施计划

版本：v2.18，2026-10-30；初版制定于 2026-10-26。用户来源决定：**停止使用 stone_new 训练，因为其仅标注光纤尖端；随后授权kidney v1/v2联合去重分组、建立新训练/开发验证版本并重训同预算基线。** 新联合数据实验已完成；下文混合来源及190张单来源实验均保留作历史对照。用户已同意[模型任务适配评估](../research/model_task_fit_review_2026-10-27.md)。[修订前计划](segmentation_temporal_occlusion_plan_v1_before_task_fit_revision_20261027.md)保留作历史记录。

## 1. 目标和本次修订

完整目标：实时识别结石与激光光纤，分析结石可见形态及有证据支持的尺寸，维持结石身份和遮挡记忆，分析光纤与结石空间关系，并在标定与观测足够时预测激光落点及其不确定性。

系统按以下职责拆分：**语义分割 → 对象记忆与实例状态 → 光纤尖端及局部方向 → 标定几何 → 尺寸、空间关系与落点可信区域。** 不再把三分类掩膜视为上述全部能力，也不预先认定 U-Net 或某一 SAM 模型最优。

本次实质性调整：

- 先纠正当前训练背景监督为零的问题；失败训练作为诊断证据，不等待跑满 60 轮后再决定。
- 建立有背景监督的纯监督基线，再逐项加入半监督、双网和替代骨干，分离训练策略与模型结构的收益。
- 将轻量运动融合与 Cutie、SAM 2.1、SAM 3/3.1 的对象记忆对照前移，先实测再决定主线。
- 单列光纤端点/方向、相机与尺度标定、尺寸准确性、激光落点验证，避免以掩膜或相对深度代替真实几何。
- 将实例身份、遮挡和真实碎裂作为独立状态问题；时序网络训练仍是条件性选项。

## 2. 固定约束

1. **video_1 和 video_2 始终仅用于开发验证。** 全部帧、裁剪、增强版本及其伪标签不得进入有标签/无标签训练、微调、蒸馏或训练集挖掘。29 帧审核标签全部保留验证，完整视频作失败片段和连续性验证。
2. 正常验证推理可以维护当前视频的因果记忆，视频结束清空；不能更新模型参数或把该视频的记忆迁移到另一验证病例。人工首帧提示仅作单列的传播上界，不冒充全自动结果。
3. 原始图像来源身份仍待核实。按文件名族分组及精确/近重复检查只能降低泄漏风险，不能证明病例独立。现有两个病例是开发验证材料，不是独立最终测试。
4. 用户已明确跳过继续人工复核；开发实验不再以重新完成 2847 张人工审核为前置条件。未审核标签保持待审；暂定背景等假设显式记录，不能改称已审核。缺少真值时限制结论，而不是反复要求复核。
5. 436 张缺少结石标注的候选不得自动变为真实无结石负帧；明确拒绝的记录继续排除。旧暂拟验证/测试图像不自动并入训练；2026-10-28用户明确授权kidney v1/v2联合重分组，新版本仅对非原test关联组重划训练/开发验证，原test关联整组保留。
6. 推理主线仅使用当前及历史帧；未来窗口、双向传播及离线回溯单列，并计入等待延迟。
7. 当前观测、历史推测形状与真实尺寸分别表达；不强制填补被光纤遮住的像素，不以固定面积或永久平滑阻止新目标和真实碎裂。
8. 原 A0、旧实验、原始数据和用户修改均保留。每轮使用新目录、固定配置、输入/源码/权重身份和可恢复断点；参数与验证口径冻结后再比较。
9. **stone_new 的全部图像退出监督、无标签、备用池、伪标签及微调训练。** 名称、路径和已知图像 SHA256 均纳入训练入口排除检查；旧混合来源权重不用于新训练初始化。原始文件与旧结果仅供追溯，不删除。历史190张kidney监督/800张备用清单保留；2026-10-28经用户授权，已建立v1/v2联合版本：521张监督训练、132张图像开发验证、144个原test关联保留组，原29帧视频验证另列。来源标签仍待审，当前无无标签或伪标签训练。

## 3. 实施顺序、依赖与当前状态

几何线：**S0 坐标约定 → S5 光纤尖端、方向和标定 → S6 尺寸、空间关系与落点验证 → S8 集成。** S5 的标定准备与独立参考几何实验可在分割训练期间开展；其正式自动量测验收依赖 S2 和 S4。

### 选择与停止规则

- 记录结石、光纤各自的 Dice/IoU、Precision/Recall、边界指标和小目标表现，不仅按二者平均 Dice 选权重。
- 同时记录无结石帧误检数、有效视野误检面积和完整视频的误检持续时间；无实例真值时不虚报实例准确率。
- 在启动新轮次前冻结开发门槛。初始筛选以同口径 A0 为参照：结石 Dice 与负帧误检面积至少不劣化，光纤 Dice 暂以不下降超过 1 个百分点为研发目标；同时单列小目标召回及误差，不将该目标当作效果承诺。
- 若验证预测接近全前景、背景几乎消失或误检持续恶化，提前结束该配置、保存诊断并定位原因；不以训练损失下降为继续依据。
- 指标冲突时报告权衡，不以光纤高分掩盖结石退化；小样本须同时报告原始计数。

交付：A0、A1-SUP、A1-DUAL、A1-SSL、A1-ALT 的数据同源对照与端到端成本；选出可靠的单帧底座。只有通过该阶段，才把自动初始化结果送入后续记忆模型。

## 13. 验收矩阵与实验决策

| 维度 | 必须记录 | 决策原则 |
|---|---|---|
| 分割 | 每类 Dice/IoU、Precision/Recall、边界、小目标表现 | 不用单一平均分掩盖结石退化 |
| 腔壁误检 | 负帧计数、有效视野误检面积、持续时间 | 不接受稳定传播的大块腔壁误检 |
| 时间连续性 | 可靠对应区跳变、短时漏检、新目标响应 | 排除永久错误掩膜造成的虚假稳定 |
| 身份/遮挡 | ID 切换、误合并/分裂、重现成功及恢复帧数 | 维持身份但允许当前可见掩膜为空 |
| 碎裂 | 事件召回、误报、父子关系与延迟 | 不为平滑外观压制真实新碎片 |
| 光纤几何 | 尖端像素误差、局部方向角、宽度误差 | 以端点和方向精度评价细光纤用途 |
| 尺寸 | 毫米 MAE、偏差/误差区间、深度与姿态分层 | 稳定性不等于真实尺寸准确性 |
| 落点 | 像素/毫米误差、置信区域覆盖、无交点行为 | 没有参考与标定则不通过物理落点验收 |
| 实时性 | 全路径 P50/P95、丢帧、等待、显存及缓存增长 | 在本机测量，不照搬公开 A100 FPS |

先冻结统计口径与研发目标，再运行新实验。有限样本报告原始计数，不虚构可信置信区间；没有真值的量不冒充有真值指标。关键阶段先用最小可解释对照排除退化，再扩大训练/依赖成本。实际收益相当时优先选择延迟更低、依赖更少且更易维护的方案。
