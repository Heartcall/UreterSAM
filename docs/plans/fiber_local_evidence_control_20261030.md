# T2-P：当前图像局部证据的最小像素对照

2026-10-30，v1。**协议已制定，像素修正尚未实现、未执行。** 本协议承接T1只读失效归因，不修改T1源码、阈值或历史输出，不训练、不改变默认模型。机器配置见[固定配置](../../configs/fiber_local_evidence_control_20261030.json)。

## 为什么先做这个有限对照

T1的视频成本通过，但图像开发集50张含光纤参考中仅11张有几何状态。23张首先因宽度族拒绝，3张杆体合格但方向未知；有些可见段短粗，PCA与FOV距离不能可靠确定真实入口/尖端。23个宽度比取倒数均落入允许范围，只证明方向敏感，**没有验证应该翻转轴线，也没有证明反转后其他条件会通过**。本协议保持T1原样，不把未经验证的位姿用于裁剪、填充或限定像素修正。

T1接受过亮斑：开发图像清单第17张（从1开始）原光纤预测1381像素，其中1267像素与来源`laser_dot`辅助标注重叠，前沿候选也在该区域。源标注仍未审核，不能升级为独立真值；但这说明高网络概率、两侧边缘和可拟合形状不足以保证光纤身份。原132图像FP中41306/58343的P_fiber≥0.9，此轮保护机制会保留这类高置信错误。身份错误须另立证据与监督方向，不能靠一个颜色阈值假装解决。

全光纤FN中，视频23574/35637、图像4111/6067的原P_fiber<0.1；这是全光纤统计，**不是尖端漏分比例**。原始fiber-expert argmax为光纤却在原始融合掩膜中缺失的参考像素数为0；T1根本不改掩膜，不能把这些FN归因于T1后处理删除。尖端独立参考未补，不能把可见前沿/PCA两端当尖端GT。

因此最小下一步检验：在当前神经概率仍有不确定性的边界，局部RGB差异是否能指导少量双向概率融合，并比相同空间采样的平均更好。它的作用域有明确上限，既不保证有效，也不解决所有漏分或亮斑。

## 三臂与真正的新增变量

| 臂 | 操作 |
|---|---|
| raw2 | 原model1两网原图输出 |
| spatial5 | 固定五点、相同不确定边界内的概率向量混合，邻居均匀权重 |
| rgb_edge5 | 相同五点、作用域、混合强度与预算，仅把权重换成当前RGB相似性 |

底座仍是未采用的model1两网49,202,790参数；原PIL256、ImageNet归一化、FP32三类softmax、原图双线性映射及光纤优先保持。另保留冻结classwise3质量参照。**RGB臂的贡献必须与spatial5直接比较**，不把整个后处理的效果都归于颜色。

与失败A+的区别是：不统一给光纤正向加分，不拟合HSV直方图，不要求真实像素蓝色；融合可增加或降低局部光纤概率，颜色仅控制邻居影响。白色、低饱和端部有同等接口。RGB差异本身不是身份判断，可能保留错误亮斑，不能预先认定会优于spatial5。

## 作用域、概率与类别映射

令s=min(H,W)/400，R=max(1,floor(2s+0.5))。对当前原始光纤掩膜用边长2R+1的方核分别膨胀和腐蚀，边界常数0；二者异或是双侧边界带。它只定义计算位置，不把膨胀区域直接纳入分割。

只处理边界带中原类别0或2、且0.1≤P_fiber<0.9的像素E。原结石类别1、高置信光纤、强背景及E以外的像素保持原类别。没有原光纤/没有E就回退原始输出，不跨图像借种子。

E大于floor(0.05HW)时，两非原始臂均整帧回退；不取top-k、不根据真值挑像素。此预算在只读作用域计数前已写入配置，计数仅估算潜在机会，不产生修正结果，也不用于调参数。

每个E像素取自身和上下左右四点，步长d=max(1,floor(s+0.5))。越界邻居权重0，中心权重1，剩余权重归一化。不能把图外补零当低亮度或边缘证据。

- spatial5：每个界内邻居权重1。
- rgb_edge5：w=exp(−mean_channels((I_neighbor/255−I_center/255)²)/(2×0.1²))。
- M为五点全部三类fiber-expert概率向量的加权平均；F_new=0.75F_center+0.25M。只在E内更新，不改stone-expert概率。

在E内，若F_new的argmax为2，则输出光纤；否则按原stone-expert argmax是否为1恢复结石或背景。原结石像素始终保护；撤掉原光纤后可能露出原结石专家预测，必须评价结石FP/TP变化。类顺序及并列处理保持0/1/2的numpy argmax规则。

若变化类别像素数大于floor(0.01HW)，整帧回退原掩膜，并记录被拒绝提案的变化统计；不能只报告提交结果掩盖失败。各帧独立，无时间状态、隐藏轮廓补全、最大组件筛除或理想模板相交。

## 只读作用域上界与能力限制

固定配置后，现有70/132仅计数E，尚未执行上述滤波。无预采样预算拒绝；E中视频FP7053、FN11721，图像FP16996、FN1742。这只是可能接触到的参考错误数，**不等于可以恢复/移除的像素数**，还没施加实际混合和变化预算。

同一E也含视频27254、图像4398个原正确光纤像素，存在损失TP的风险，不能只看错误上界。原结石保护锁住的视频85、图像523个GT光纤像素，以及全无种子的445像素图像仍不可修复。超过概率保护范围的FN/FP也不会改变；历史可用性、方向推断和物理端帽未因该方案得到验证。

轻量方案值得用有限对照证伪，原因是没有新网络、共享模板或训练，增量仅五点采样、一个混合系数与一个RGB尺度；失败可以明确结束局部后处理路线。它不能替代后续身份诊断、可靠端部监督或必要的网络改进。

## 固定实施、评价与完整视频要求

后续先新增独立后处理与实验入口，不改旧入口/T1源码。先做解析机制测试，再202张原图新推理：网络概率可共享给三后处理，实际各应用202次，准确记录只有202次静态网络调用。参考、来源与未知255规则不变。

每个臂分别对video_1全部722帧、video_2全部1972帧运行独立新进程，**6进程共8082正式前向帧**。每进程12帧预热不计入正式帧。即使静态或成本失败也完成两片，不免测。视频输出仍只在70帧有精确参考处报告精度；42/120抽样未齐、其余无像素真值帧不称全片准确率。

记录神经网络、映射/传CPU、边界/E、采样/融合、类别映射/回退以及直接总管线p50/p95/max；同时报告含解码/编码/核验/导出的实际吞吐、CPU/GPU开销。三臂传同样原图三类概率与掩膜。额外后处理p95≤5ms只是设计目标，每片总管线还须直接≤1000/FPS，不相加/相减p95推导通过。

所有结果报告两类Dice、Precision、Recall、边界F、可见语义中心线、TP/FP/FN与被删除的原TP；保留逐帧70/132及原29/新41、43/27病例、68/64来源、25/107曝光。所有拒绝、预算回退、实际改变帧及失败示例均保留。输出两片完整input/raw2/spatial5/rgb_edge5对比及不确定区、变化图；固定T1失败帧同时查看。

## 预冻结质量门槛与停止条件

1. 原29筛选与`compare_two_network_experts_20261029_v2.json`的全部门槛保持；70/132八项结石/光纤Dice、Precision、Recall、边界F分别与同轮raw2和冻结classwise3比较，epsilon=1e-12。不能仅Precision提高而Recall或边界下降。
2. 额外TP保护：每类每个70/132集合，粗删除TP≤floor(0.001×原TP)、净TP不少于原TP；每帧删除TP≤max(1,floor(0.005×该帧GT类别像素数))。报告违反帧，不能靠别帧补回掩盖局部损失。这些是新增前瞻约束，不替代或放宽已有门槛。
3. 同时满足各门槛后，70与132都须至少一类FP或FN严格减少，才称有开发改善。RGB相对spatial5无增益就明确否定颜色权重的额外价值。
4. 所有6进程、输入/源码/权重/输出身份、保护不变性和因果/边界行为核验通过，两个完整视频满足直接耗时预算。通过也不自动改默认模型，独立泛化和尖端真值仍待补。
5. 只运行固定三臂，不扫alpha、sigma、概率阈值、半径、预算，不扩大高置信度修改范围，不事后改门槛；失败保留负结果并停止，不自动训练或进入结石记忆。
