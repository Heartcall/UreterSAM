# UreterSAM 分割时序与遮挡改进实施计划

制定日期：2026-10-26。

本文件记录实施顺序与任务状态。2026-10-27 已执行 S0/S1 自动化任务，完成 29 帧视频像素审核与 S2 工程准备；用户随后明确拒绝进一步复核并要求进入下一步，已启动 S2 的 A1_DEV 开发重训。用户进一步指定两段视频仅作验证；已停用含 video_1 训练帧的旧实验，并在纯图像训练清单上重新启动，不继承旧权重。详见[当前训练记录](../progress/2026-10-27-a1-videos-validation-only.md)。未完成审核的事项保持待审，开发实验不等于病例独立验证。技术依据见 [调研报告](../research/temporal_occlusion_segmentation_review_2026-10-26.md)。

## 1. 目标、实施原则与依赖

核心目标：减少腔壁大块误检、跨帧忽隐忽现，以及光纤遮挡引起的错误计数和尺寸突变，同时保留对真实碎裂、新目标入镜和目标出镜的响应。

执行顺序：

**S0 固定基线与评价协议 → S1 修复数据语义并建立视频样本 → S2 重训单帧对照 → S3 运动对齐与时间融合 → S4 实例身份和遮挡几何 → S5 视频记忆模型对照 → S6 条件性训练时序网络 → S7 集成验收。**

- S0、S1 是后续实验的前提。S2 提供修复数据后的共同分割底座，后续比较不混淆数据收益与时序收益。
- 用户最新指令允许先做来源未核实的开发性 S2 实验，同时要求 video_1 和 video_2 仅作验证。当前 A1_DEV 训练仅含原始图像数据的 350 张部分标签和 1669 张无标签图像，不使用这两段视频的任何帧作训练或伪标签学习；29 帧审核掩膜作开发验证，完整视频作验证回放。此前含 video_1 的实验已作废，不继承其权重或沿用其收益结论。未审核标签及病例信息保持待审；训练原始来源与视频的潜在同病例关系未知，可信 A1 的完整数据验收仍未完成。
- S3、S4 先建立可解释、可消融的轻量方案；S5 判断更强记忆模型是否值得引入。
- S6 只在前面实验暴露明确不足且连续标注足够时执行。无需为了完成流程而强行替换网络。
- 推理主路径只使用当前及历史帧。使用未来帧、双向传播或历史回溯的方法单列离线/有延迟对照。
- 可见掩膜、跨帧身份和历史推测几何分开保存；不以强制掩膜连通或固定面积替代遮挡建模。
- 每阶段保留独立输出目录、配置、权重身份和结果；现有权重、数据与未提交修改不被覆盖。

## 8. S6：按实验结果决定是否训练时序网络

### 启动条件

B2/C1/C2 仍存在明确的领域误检、遮挡恢复或边界不足；已有真实有序片段、可靠分组与足够关键区间标注；当前硬件具备可接受的训练成本。

### 任务

- [ ] 首先尝试在现有编码器上增加单向 ConvGRU/ConvLSTM 或小型时序注意力；采用历史窗口，避免直接引入未来帧。
- [ ] 以当前单帧权重初始化，并保留相同数据的单帧重训对照。
- [ ] 建立片段采样与几何一致增强；时间间隔变化作为可控因素，而非打乱帧序。
- [ ] 仅在可靠可见对应处加入时序一致性，给遮挡、新显露区域和真实碎裂保留自由度。
- [ ] 使用空间监督、时序监督和半监督伪标签的独立开关；按失败类型验证，而不是只优化平均 Dice。
- [ ] 如轻量结构仍不足，再选择一种较复杂的视频分割结构；不同时堆叠多种时序网络使收益无法归因。

### 交付物与验收

交付 D 组时序权重、训练配置、消融与在线成本。若它未优于更简单的 B/C 方案，则保留更简单方案，并记录不采用的依据。S6 不满足启动条件时明确跳过，不阻碍 S7。

## 10. 验收指标与首轮目标

下面是用于 S0 冻结的**建议研发目标**，不是已经测得的改进或效果保证。根据基线、事件数量与数据可信度，在验证集上一次性明确统计口径；独立测试集不参与阈值设定。小样本时同时报告原始计数和不确定性，不强作百分比结论。

| 维度 | 必须记录 | 建议首轮目标 |
|---|---|---|
| 腔壁误检 | 无结石帧误检率、有效视野误检面积、连续误检持续时间 | 相对 A1 降低大块误检总持续时间约 30%，且不增加长时间持续误检事件 |
| 时间连续性 | 可靠可见对应区的运动补偿后标签跳变；短时漏检区间 | 明确减少孤立跳变；同时排除永久错误掩膜造成的虚假稳定 |
| 分割质量 | 结石/光纤 Dice、IoU、Precision、Recall，按困难场景分层 | 时间模块引入后的结石 Dice 下降不超过 1 个百分点，并单独检查小目标召回 |
| 遮挡身份 | 错误分裂/合并数、遮挡前后身份保留、重现恢复帧数 | 错误分裂明显减少；把重现后 5 帧内恢复作为初始观察目标 |
| 真实碎裂 | 事件召回、误报、父子关系及响应延迟 | 不能为稳定外观而明显降低碎裂/新碎片召回；样本不足时逐事件回放，不给出可靠性承诺 |
| 尺寸 | 无遮挡/遮挡/重现的测量变化及有效性标记 | 遮挡期间不输出未标记的伪精确测量；稳定性与尺寸准确性分别报告 |
| 在线能力 | 计算吞吐、端到端 P50/P95 延迟、窗口等待、峰值显存、状态增长 | 以 30 FPS 输入为工程目标核定预算；不满足时明确瓶颈及实际延迟，不用离线 FPS 代替实时验收 |

## 11. 测试与决策规则

- 数据检查：类别别名、标注不完整、空目标、重叠优先级、来源合并和分组隔离。
- 算法检查：已知位移的历史对齐、越界/遮挡低可靠区域、一个实例多片区、完全遮挡重现、真实分裂、相邻对象不误合并及状态重置。
- 回归检查：原样模式、坐标映射、日志可复现和不覆盖旧产物。
- 性能检查：短片段与长视频分别运行，统计完整处理路径和资源增长。
- 选择原则：每次只引入可归因的变化；准确性、错误持续时间和新事件响应一起看；实际收益相当时选择依赖更少、延迟更低且更容易维护的实现。
