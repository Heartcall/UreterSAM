# 可靠远端单向搜索：单因素执行协议

2026-11-02。按主计划v2.28及用户继续指令，先冻结此协议，再实现/实验。单因素仅为：**搜索方向从两端改为仅搜索既有规则能够确定的远端；方向歧义时不生长。** 不同时改变颜色、种子、背景采样、形态容差、端帽或质量门槛。

三臂：raw2原两网、blue_extent上一轮冻结双端候选、distal_only新单向候选。旧源码、配置、结果均保留。全部底座和数值从`configs/fiber_blue_extent_control_20261101.json`逐项继承，包括背景≥6有效点；第1209帧5点的已知失败不在本轮修补。

## 唯一变化与回退

复用原BlueExtent种子资格及同帧颜色锚点，在种子合格后、实际walk前计算方向。算法原样：两种子端到图边缘距离差≥0.02D则较近者为入口；否则仅在原compatible_history通过（age≤3、模π轴夹角≤15°、法向距离≤0.04D、宽比0.5–2）时使用前帧T1消除轴符号歧义。两者都不能确定则方向ambiguous。

这里“可靠”仅指通过上述既有启发式的资格，未由真实入口/物理尖端标注验证；不能保证符号一定正确。记录current_border_hint/prior_resolved/ambiguous，不根据验证图像重新挑选方向。

非歧义时仅调用原walk一次，sign为该远端；另一端保留原种子截面作为未搜索元数据，无新增多边形、无形态异常、不检测其末端。歧义时两端都不调用walk，返回空新增，末端unknown且没有坐标。不因任一未搜索端补线、拟合或追加搜索。

搜索的远端使用原颜色、双/单侧证据、宽度/方向/曲率/有限段数、轴向RGB见证、T1弱边否决及黑隙/遮挡停止；该端异常仍拒绝整帧新增，不保留异常前一段来规避拒绝。原面积预算、原石头连通前屏障、4连通根、原类别保护完全不变。差异源于不搜索另一端及其派生的少计算、少候选/冲突、不再受其异常清空，不是另加“宽松回退”。

端帽规则原样，只对已定向的远端尝试，仍不要求先新增像素；未知/遮挡/范围结束不产生确定尖端。保留唯一实例可见片段不连通的可能，不连接隐藏部分。T1每帧仅从原概率更新，绝不反馈新候选；两臂的T1原始状态/prior应一致，静态无视频状态。
