# 蓝色光纤连续延伸：五项判断原则与分支约束

2026-11-01。落实用户提出的五项原则，补充上一版不同明度蓝色本体设计。**这是候选设计要求，不是已实现算法或数值执行协议。** 不改旧源码、默认推理、模型权重、标签或历史结果；无训练和新增候选实验。

## 1. 颜色与亮度分开

采用当前帧归一化RGB色度`c=RGB/(R+G+B+epsilon)`、相对蓝色优势`b=c_B-(c_R+c_G)/2`及主体/侧背景对比。`b`是证据特征，不是光纤身份概率，也不单独决定接纳。浅蓝逐渐变成深蓝不能仅因亮度变化被截断；亮度用于曝光/噪声可靠性诊断，不设蓝色最低亮度硬门控。

原网络高置信主体建立本帧身份锚点，生长不无约束更新颜色模板，不跨视频保存颜色统计。阴影色偏、过曝和近黑噪声可能改变色度：颜色不可靠就降低证据等级，不能因归一化后一个噪点“很蓝”而接纳。真正RGB近零且不可辨的间隙没有可靠色度；不能把“不设置V阈值”误解成必须穿过黑区。

## 2. 与当前可信主体可见连续

新像素必须通过当前图像支持的路径与选定可信主体相连，沿已确认前方搜索。独立蓝块、组织蓝色反光和跳过一段未知后才出现的蓝色均不自动接纳。原已有其他可见片段仍保留同一实例身份的可能性，但不能用连接操作填补它们之间的隐藏部分。

不能使用膨胀、闭运算、跨空白最短路或预测轮廓补桥。原结石在连通提取前作为屏障；屏障前潜在冲突另存审计，不能把冲突统计路径用作真实生长路径。

## 3. 细长管体形态相容

检查候选与可信主体的方向、局部宽度、宽度沿轴变化、侧边片段和局部曲率。内部强明暗边不等同于外边界；拟合外形只限制搜索及评价，不能将理想管体多边形直接填成可见光纤。

形态应容忍模糊和圆钝端帽引起的小范围宽度变化，不强制每步严格变细，也不允许宽度/方向无证据突变。容差与曲率定义必须在新实验前一次性数值登记，不能按1209或验证成功帧调节。最多一根光纤不等于必须从多歧义主体中选一根。

## 4. 单侧弱边是受约束的分支

将两侧分别标记为`observed_strong`、`observed_weak`、`out_of_view`或`unknown`，避免将裁切当低对比、将未知当已观测。允许局部一侧弱边；清晰侧须确实对应当前管体/背景外边界，内部须有连续RGB蓝色支持，局部宽度和轴向变化必须能由本帧可见区域与相邻可靠截面约束。

**弱边分支必须比双侧强边分支更严格**：提高颜色连续性与背景分离要求，收紧宽度变化/方向/曲率容差，并要求非过期、同病例且当前兼容的T1几何状态。参数大小和单侧段的有限长度/截面预算须在执行协议冻结；不得把弱边模式无限延长至整根虚构光纤。

T1只做这一分支的兼容性约束/否决，不能提供可见像素证据、延长未知区或把此前生长结果回馈为独立网络证据。强而无歧义的当前双侧观测不被旧预测一票否决；当前/历史冲突时退出弱边分支，继续保留原网络输出和独立当前观测，不锁死旧位姿。

静态图像不得借用视频状态；没有有效历史时，单侧弱边区域只能输出未接纳的诊断候选，不能冒称满足时序条件。视频初始、状态过期、病例/图像尺寸/时间重置后同样处理；历史未到位不妨碍正常强当前证据分支建立观测。

这与旧B1/B2“候选必须相同、T1只提示”的有限对照不同：新候选中T1可以**否决当前弱边候选的接纳**，但不能独自产生候选。旧B1/B2不修改，新分支另立协议与对照，不能沿用旧候选相同结论。

## 5. 不可见区域必须停止

真正黑色间隙、遮挡、颜色噪声不可辨或没有当前图像证据时立即停止该方向的新增；不越过再寻找蓝区，不用时序位姿或理想侧边填回。仍允许保留原掩膜的独立可见片段，停止新增不意味着删除原正确像素。

**停止生长不是确定尖端。** 只有当前外轮廓圆钝收拢、端部边界及端外可见背景共同支持时才输出可见末端候选。内部蓝色亮暗过渡后仍有管体证据时继续；遮挡、出视野、计算范围终止、弱边证据不足分别记状态，不当成最终尖端。没有独立尖端真值，定位准确性依然未验证。

## 实施和验证要求

下一步仍是冻结**一个**新候选的数值协议；一次登记颜色可靠性、双/单侧资格、弱边更严格的具体值、T1有效性/重置、最大弱边连续段、端帽和拒绝规则。不是本轮直接修改掩膜或部署。

预期新增机制测试：共同亮度缩放下的蓝色兼容；浅蓝—深蓝过渡不断开；真正黑隙/遮挡不桥接；独立蓝块不吸附；宽度/方向/曲率异常拒绝；单侧弱边有兼容历史才接纳、无历史不接纳；历史不能生成当前无证据像素；强当前证据不被陈旧历史锁定；静态与病例/时间重置无状态泄漏；无新增帧仍检查端帽；计算范围终止不产生确定尖端；原结石/光纤像素保护。它们当前是待实现的测试清单，未称测试已通过。

每个实际实现的候选仍须完整运行video_1全部722帧及video_2全部1972帧，即使静态失败也不免测。报告70视频参考、132图像、原29/新增41/最近5、病例/来源组、暗段FN、TP/FP变化、异常与回退、独立进程P50/P95和含导出吞吐，保留全部争议/拒绝样本。

新候选的单侧分支依赖因果状态，**不得再要求其静态与视频候选逐像素相同**。原网络概率/原掩膜仍须一致。70帧分别报告独立重置静态诊断和完整视频因果输出对齐参考的指标；132图像独立无状态评估。新协议必须在实验前明确哪种70帧口径用于门槛，不能看结果择优或混合。既有98%新增候选Precision、10%低Lab FN下降、质量不退化、原正确像素零删除和5ms额外p95/源帧总预算不放宽。

视频/派生物仅开发验证，不训练、不拟合共享模板；stone_new继续排除训练，不读144保留test像素。原A0默认、权重、标签和521/132/144/29及现70全部冻结。训练、默认替换、真实标定和结石记忆不随本次原则更新启动。
