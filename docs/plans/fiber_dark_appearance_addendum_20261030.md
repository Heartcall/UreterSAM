# 暗色可见前端漏分：任务优先级补充

2026-10-30。用户指出：暗光时光纤头颜色更暗、更深，分割常把这一段排除，导致光纤明显截短。此观察作为专项问题前置；原T2-P配置/门槛保留，不把局部边界滤波当作完整暗尖端恢复方案。**本补充不执行新修正、光度变换、训练或默认替换。**

## 已得到的证据

对原70视频参考和132图像开发参考，只读复算model1两网与冻结classwise3缓存，没有新网络前向。用原图像素HSV V与Lab亮度编码等宽三分组；Lab值是显示图像的亮度代理，不是相机照明/辐照度测量。深蓝的V可能仍高，不能只用V描述视觉明暗。

视频70帧中，model1对低Lab亮度光纤参考像素的Recall为0.6212，中亮0.9478，高亮0.9987；classwise3相应为0.5601/0.9360/0.9994。低亮组中，去掉距语义参考边界3像素以内的区域后，内部像素Recall仍仅0.7145/0.6456，因此不足以把全部暗色漏分解释为轻微边界偏移。像素并非独立样本，两病例和各帧结果另存，不把关联当成亮度的因果证明。

第1209帧RGB、审核整帧参考、原掩膜、原概率和FN图共同显示：可见暗蓝前段被原网络赋低光纤概率，当前原掩膜显著截短。model1该帧低Lab亮度组GT2776像素、TP150、FN2626，其中2521个FN的P<0.1；原T2-P作用域仅覆盖105个该组FN。这是全光纤亮度分组，不是独立尖端参考区域的Recall。classwise3也有同类截短，不能把问题只归于单成员选择。

T1该帧当前候选未通过双边缘检查，没有可用当前几何观测。不能把本例描述成T1后处理删除了头部；也不能保证从错误/缺失位姿出发直接延长模板会正确。所有模型、标签及输出未改。

## 对后续路线的影响

1. **优先制定暗端专门的受控诊断/方案。** 原始网络证据、当前颜色/亮度差、真实可见端部与几何搜索范围应分别检查。不同亮度下的同一实例外观可以变化，杆体与头部不要求完全相同的色相、饱和度或亮度。
2. 下一份协议先明确最小端部参考与不确定区域，利用既有12帧入口；没有尖端独立参考时，只能报告整帧分割、亮度组与定性暗段覆盖，不能自动生成尖端真值或宣称真实长度恢复。
3. 研究推理侧亮度/色度表达与原始概率响应的固定对照，具体变换、融合、样本、完整两片测试和停止门槛须在实验前另行冻结；不能按验证结果反复选gamma、增强强度或颜色阈值。输入增亮未必有效，也可能扩大组织/高光误检。
4. 研究杆体证据与独立暗端外观的配合。几何/历史可以提出搜索候选，当前图像仍须支持可见像素；不能把杆体到暗段的内部明暗变化直接当物理末端，不能填没有证据的预测头部。
5. 原T2-P保留为局部边界对照，尚未实现。它保护P<0.1、P≥0.9及原结石，只在窄边界里处理，不应以扩大半径、降低保护阈值或硬延长来绕过已冻结协议。若以后运行，须附带固定亮度组的TP/FP/FN与Recall，不用总体收益掩盖低亮组退化。
6. 若证据最终支持网络对暗头外观泛化不足，再核对有标签数据的真实增强路径、端部监督与尺度影响，提出独立训练计划并等待批准。不能仅凭当前关联就认定训练增强是唯一原因，更不能自动训练。
