# D1 尖端参考与完整视频分层抽样标注

本协议落实用户“每种方案在两个完整视频测试分割精度”的要求，以及随后选择的“没有完整标注，增加完整视频的分层抽样标注”。不要求补齐2694帧稠密标注，也不重新要求审核全部训练数据。

## 已冻结的样本

- 视频总体：video_1 为722帧，video_2 为1972帧，均从第0帧顺序解码；2694帧RGB身份与D0日志全部一致。
- 概率样本：每段视频分12个连续时间层，每层无放回随机抽5帧，共120帧。时间层由`numpy.array_split`生成；种子分别为2026102901和2026102902。抽样不读取图像特征或模型结果。
- video_1 第78帧（零基77）随机入样，已有原人工参考，可直接保留；其余119帧需要新标注。
- 原29帧仍作为固定诊断集；其中未随机入样的28帧不混入总体精度估计。已知失败片段不因效果好坏替换随机样本。
- 12帧尖端专项保留D0既定名单，每病例6帧。它们用于尖端归因，不代表随机总体样本。与概率样本重叠时也只计算一次对应的总体抽样权重。

清单见`runs/fiber_reference_d1_20261029/sampling_plan.json`和`sampling_frames.csv`。CSV同时列出零基索引与从1开始的帧号，页面显示从1开始的帧号。原521/132/144/29数据划分不变；新参考均为验证旁文件，不能用于训练、伪标签学习或模板标定。

## 页面操作

运行本地页面：


访问 http://127.0.0.1:8768/ 。页面顶部切换“12帧尖端专项”与“120帧全片分层抽样”。没有模型预填标签；新帧全部初始化为255未知，而不是背景。原29帧分割参考只读。

### 尖端专项

1. 先看原图，确认可见末端是否存在。仅将可观察到的最远端圆钝端帽，以及有明确外观边界的暴露端部标为尖端；不得把轴向最后15%自动当作尖端。
2. 手工框出整个可见尖端及周边负像素。评估框不能只紧贴正像素，否则Precision没有有效的负样本范围。框坐标为原图像素，右/下边界不包含在框内。
3. 橙色为可见尖端，青色为可确认杆体，绿色为确认非光纤，灰紫色为未知。杆体与端部界限无法确认时，保留未知并备注；不强制按几何模板划分。
4. 画笔或多边形描出可见像素；可以手动将框内未知区标为非光纤后逐像素核验、画回目标及未知区。该按钮只是标注操作，保存待审不会产生已审核真值。
5. 标记可见末端点；入口点仅在可以确认时填写。末端点不是被遮挡的物理尖端外推位置。
6. 完全遮挡、出视野或无法确认时选择相应状态，不补尖端像素或端点。此类帧保留为失败/可见性诊断，不计算可见尖端Recall。
7. 可打开原29帧分割作为上下文。新尖端标注与旧整体光纤参考不一致时，写明原因；不能为迁就旧掩膜而删掉人工确认的可见端部，也不覆盖旧标签。
8. 填写审核人，勾选独立可见像素核验及评估框审核后确认参考。尖端Precision忽略框内已确认杆体和未知像素，使用尖端正像素与非光纤负像素；不把杆体误当尖端FP。

### 全片分层抽样

1. 核验整幅原图，分别标注结石、可见光纤与背景。不能只标尖端。
2. 无法确认的反光、遮挡边界等保留255；不可见的结石或光纤不补全。一个光纤身份允许有多个不连通可见片区。
3. 可以将未知区手动标为背景后修正目标，但必须检查整帧再确认。“没有画到”不能自动代表背景真值。
4. 填写审核人、整帧审核与独立可见像素核验，再确认参考。暂时未完成时保存待审；待审版本不参与精度计算。

所有保存采用独立版本及哈希，旧版本保留。页面切换未保存样本时提示，过期页面保存会被版本冲突检查拒绝。服务仅监听本机；原始图像和旧参考变化会停止读取/保存。

## 精度统计口径

每种实际方案仍必须输出两个完整视频的全部722/1972帧。每帧原图尺寸、类别0/1/2及文件身份均检查；缺失输出不得悄悄跳过。全片性能仍需独立进程实际推理、全帧P50/P95和吞吐，缓存精度审计不充当速度实验。

精度分开报告：

| 结果 | 参考条件 | 含义 |
|---|---|---|
| 原29帧诊断 | 原人工参考 | 复现历史、逐帧失败分析；不是全片无偏估计 |
| 每片分层抽样估计 | 对应60帧全部审核 | 对该完整视频的像素池化Dice、Precision、Recall估计 |
| 两片合并估计 | 全120帧审核 | 以帧数和时间层总体大小加权，不将两病例简单等权 |
| 稠密逐帧精度 | 全部2694帧都有独立参考 | 当前不具备，保持null |
| 尖端专项 | 独立尖端ROI、可见像素与负像素审核 | 12帧专项归因，不外推到全片尖端总体 |

层`h`总体帧数为`N_h`，抽样帧数`n_h=5`。先用权重`N_h/n_h`估计混淆矩阵的总体计数，再从加权TP/FP/FN计算比率；不能简单平均各帧Dice。video_1层权重为12或12.2，video_2为32.8或33。

参考未齐时不发布部分样本外推的总体精度。每病例可在其60帧齐备时独立估计；合并估计等待120帧齐备。未知像素排除并报告原始/加权数量和占比，因此指标仅描述可判读像素，不能掩盖大面积未知。

估计区间采用分层有限总体方差`sum_h N_h²(1-n_h/N_h)S_h/n_h`及比率的delta近似，报告近似95%范围。这是条件于这两段开发视频的抽样不确定性，不是患者泛化区间。每层仅5帧时区间可能不稳；若样本未观察到错误，正态近似可能退化为零宽度，不能解释为总体没有错误或精度保证。

## 评测与停止条件

完成标注后，使用**新输出目录**重新评测，不覆盖本轮初始结果：

```powershell
python -m tools.fiber_reference_evaluation --output runs/fiber_reference_d1_20261029/accuracy_after_review_v1
```

评测输出各方案/各视频参考覆盖、全帧文件身份、逐帧指标、原29帧Dice/Precision/Recall、3像素容差边界F，以及相对冻结classwise的原正确像素删除、恢复与FP变化。尖端参考通过后才计算ROI内TP/FP/FN、Recall、Precision、Dice与可计算的边界F。语义方案没有经过验证的末端点输出，尖端定位误差保持不可计算。

本轮只补参考与评测基础设施。A+尚未执行；待必要参考可用后，先完成杆体/尖端颜色和概率归因，再冻结正向软补充方案。颜色/几何统计只能来自训练专用资料，不能用新验证标签拟合。质量门槛不放宽，高置信度真实像素保护与首次试验零删除预算保留。训练侧改动仍需另行计划与批准。

如果尖端不能可靠分辨，保留未知、记录原因，尖端指标不发布；如果样本尚未审核，停止发布总体精度估计，但不影响已有全片输出和性能诊断。出现身份错位、原标签变化、预测缺失或非法类别时不通过覆盖审计。默认模型、权重、旧结果及结石时序阶段均保持原状态。
