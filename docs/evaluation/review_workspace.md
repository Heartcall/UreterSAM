# 本地标注复核工作台

本工具用于完成 S1 的实际标注与审核。模型预标注不会自动成为真值，原始数据与预标注文件不会被覆盖。

## 启动与恢复

在项目根目录、`uretersam` 环境中运行：

```powershell
python -m tools.review_server --port 8767
```

浏览器打开 <http://127.0.0.1:8767>。仅监听本机地址，不上传图像到外部服务。关闭服务后，使用相同命令会恢复同一会话。一个会话请只运行一个服务进程，可以通过多个页面浏览，过期页面保存时会提示重新载入。

默认连接顺序解码的 `user_events_20261027_v3` 关键帧和 `ureter_semis_v2_review_20261027` 训练草稿。保存位置为 `runs/annotation_sessions/review_20261027`，可用 `--template`、`--dataset`、`--session` 指定其他已对齐材料和新的会话。

## 复核视频关键帧

1. 选择“视频关键帧”，显示编号与用户使用的从 1 开始帧号一致；导出记录仍使用从 0 开始编号。
2. 查看原图和上下文视频，使用结石、光纤、背景、未知四类画笔或多边形修订可见掩膜；可隐藏标注、调整透明度，或撤销最近的修改。上下文采用本地逐帧 JPEG 回放，避免浏览器不支持既有 MP4V 编码；播放结束后收起并再次打开即可重放，回放画面不作为像素真值。
3. 填写审核人、结石存在性、光纤标注完整性及备注。不确定区域标为未知；完全遮挡不等于真正无结石，不能据此随意确认无结石负样本。
4. 尚未审核时选择“保存待审修订”。明确核验后才选择“审核通过并保存”。像素审核和实例审核分别记录。

“跨帧实例与遮挡”用于手动指定身份。结石画笔的实例编号为 0 时只修改类别；设为正整数时，同时为涂到的结石像素指定身份。同一视频的同一结石跨帧使用相同编号，一个编号允许多个不相连的可见片区。光纤像素不改成结石来维持连通性。

每个实例填写当前状态：正常可见、部分遮挡、完全遮挡、失跟、离开视野或分裂待确认。完全遮挡/失跟的实例可以没有可见像素，身份仍可记录。真实碎裂经过复核后可填写父实例编号。勾选实例审核时，所有可见结石像素必须有身份，身份像素与当前状态必须一致，父子关系不能循环或在同一视频中自相矛盾。

这些是人工标注功能，不是已实现的自动时序分割或跟踪算法。现有 29 帧仍是稀疏起点，不能视为已完成遮挡区间密集标注。

## 复核训练数据

选择“训练数据草稿”，可以筛选全部 2847 张图像、436 张无结石标注候选、232 张有光斑但无光纤标注的图像和 3 张含未知类别的图像。

可独立修订标签、记录存在性与光纤标注完整性。原病例或原视频关系未知时，保留来源未核实，保存为待审。文件名前缀只是线索，不能用于勾选“已核实”。批准训练样本需要审核人、明确存在性、完整光纤标注及已核实的来源标识；后续清单升级工具还会检查分组隔离和正负样本覆盖。

“确认标签，保留来源待审”允许完成像素标签、存在性和光纤完整性审核，单独记录 `pixel_review_status=approved`，训练审核仍为 pending，来源仍保持未核实。“无结石候选 · 标签待审”会跳过已完成标签复核或已排除的候选；候选原图也可能实际有结石，应按画面修正而不是照文件状态确认不存在。已保存待审修订不等于已确认标签。

当前已完成的 29 帧视频像素审核保存在 [冻结快照](../../runs/review_snapshots/video_keyframes_20261027_v2/pixel_reviews.json)，[A0 评价报告](../../runs/review_snapshots/video_keyframes_20261027_v2/report.md)已生成。视频审核与训练草稿审核为两项独立进度；这些视频关键帧保持开发评价用途。

“排除该样本”只改变会话中的审核决定，不删除源文件。保存待审可以重新打开之前的审核决定进行修订；每次保存创建新版本。

## 保存与导出

- `session.json`：当前审核决定，可恢复会话。
- `revisions/`：每次保存的类别 PNG、16 位实例 PNG、审核人、时间、来源与内容哈希；旧版本保留。
- `pixel_reviews.json`：供已有视频像素评价入口读取；未审核项不参与准确率计算。
- `dataset_reviews.csv`：供已有训练数据清单升级工具读取，修订掩膜路径相对会话目录。

审核完成后可运行：

```powershell
python -m tools.evaluate_video_annotations --config runs/baselines/a0_20261027/config.json --annotations runs/annotation_sessions/review_20261027/pixel_reviews.json --output runs/annotation_sessions/review_20261027/a0_pixel_metrics.json

python -m tools.promote_review_dataset --manifest datasets/ureter_semis_v2_review_20261027/manifest.json --reviews runs/annotation_sessions/review_20261027/dataset_reviews.csv --output datasets/ureter_semis_v2_review_20261027/manifest.reviewed.json
```

没有已批准像素掩膜或没有足够已核实数据时，这些工具会拒绝评价或升级；工作台不会自动启动训练。保存后的掩膜被外部修改时，哈希检查会要求核对记录。

标注定义与坐标约定见 [标注协议](video_annotation_protocol.md)。
