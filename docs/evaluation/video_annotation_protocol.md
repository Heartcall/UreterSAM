# 视频与数据标注协议 v1

适用阶段：S0/S1。制定日期：2026-10-27。

## 身份与帧号

用户已确认 `video_1`、`video_2` 来自两个不同病例，使用匿名身份 `case_video_1`、`case_video_2`。这不代表它们与原训练图片的病例独立性已经核实；目前都用于开发复核。

`compare_1` 和 `compare_2` 与各自原视频帧数一致。对比视频显示编号从 1 开始，日志、掩膜文件名、标注清单从 0 开始。用户给出的包含端点区间 `[a,b]` 统一转换为 `[a-1,b)`。原视频帧是标注坐标基准；256×256 预测图仅供对照，不是像素真值。

## 必须区分的证据

- `user_reported_event`：用户指出的误检/闪烁/遮挡区间，可用于优先复核。
- `automatic_candidate`：预测面积或未补偿标签变化筛出的候选，不证明算法错误。
- `pixel_ground_truth`：审核后的可见掩膜，才可用于 Dice/IoU、误检像素与漏检像素评价。
- `instance_ground_truth`：跨帧实例身份、可见片区与父子事件关系，才可用于错误分裂和身份指标。

## 可见性、身份和事件

1. 可见掩膜：0 背景，1 结石，2 真实光纤，255 未知/无法可靠标注。激光光斑独立辅助标注，不直接等于光纤。
2. 有效视野单独标注，黑边不等于正常腔壁。基线中的自动视野估计只作诊断。
3. 同一颗结石被光纤遮成多个可见片区时仍使用同一实例身份；不要人为填成连续的可见结石掩膜。
4. 部分遮挡、完全遮挡、失跟和离开视野分别标记；完全遮挡时可见掩膜可以为空。
5. 真实碎裂需记录父子实例，结合视频中的相对运动/可见间隙核验；不能只由一帧连通域数判断。
6. 测量的当前可见几何、历史几何和隐藏区域推测分层记录；没有真实尺寸时只评价稳定性。

## 数据审核与训练入口

`datasets/ureter_semis_v2_review_20261027/manifest.json` 是待审草稿，训练入口明确拒绝。

在 `review.csv` 中保留 `sample_id`，人工或经认可的审核者填写：

| 字段 | 允许值/含义 |
|---|---|
| review_status | pending / approved / rejected |
| reviewer | 明确的审核者标识，approved 时必填 |
| stone_presence_review | present / absent；应与最终掩膜一致 |
| fiber_annotation_completeness | complete；包含确认光纤真实不存在的情况，不确定时不批准 |
| source_group_verified | True；必须核实原视频或病例，不把文件名推测当作确认 |
| patient_id / video_id | 至少一个原始来源身份；跨数据源的同一来源使用一致标识 |
| corrected_mask | 可选，更正后的原图分辨率 0/1/2/255 掩膜路径，相对 review.csv 所在目录 |
| review_note | 歧义、修正和排除依据 |

审核后的清单通过以下工具生成，默认不会覆盖草稿或旧清单：

```powershell
python -m tools.promote_review_dataset --manifest datasets/ureter_semis_v2_review_20261027/manifest.json --reviews datasets/ureter_semis_v2_review_20261027/review.csv --output datasets/ureter_semis_v2_review_20261027/manifest.reviewed.json
```

工具会把已验证的病例/视频、原图族及完全相同图像合并分组后划分；冲突重复标注、缺失审核、无可信负样本或不完整集合会拒绝进入训练。图片名称只提供线索，不能恢复真实视频时间戳。

## 评价约定

- 所有无标注视频指标只能称预测诊断，不称准确率、误检率或遮挡恢复成功率。
- 在有效且标注可靠的对应区域上评价时序一致性，另报真实变化响应。
- 无监督面积/跳变阈值 0.25 只用于筛选复核候选；不得用它代替误检真值。
- 延迟分开记录读取、预处理、模型、后处理与导出；基线没有加入单目深度或几何分析，其耗时不能代表完整临床辅助管线。
- 当前独立测试真值尚未建立。不得把同一开发视频的相邻片段视为独立病例测试。
